# game015 — 落下キング

- 面白さの核: スクロールに追われながら安全な短い着地と、深く進める欲張り落下を選ぶ。
- 失敗: 落下距離超過、危険物、スクロールに追いつかない。結果で死因を明示する。
- 今回の改善: 足場距離差、狭い/広い/柔らかい/崩れる足場、下ホールド連続降下、練習更新。正確な閾値は現在のmanifestとコードを参照。
- 操作: 左右キー/画面ボタン、下キー/DROPホールド。ジャンプなし。
- タグ: fall / precision / pixel-art / retro / hard。安定IDと日本語ラベルはcatalog.jsonを参照。
- UI懸念: 下ホールドで通過する床と止まる床の違い、危険な高さ、死因を小画面でも読めるか。
- デザイン: 王冠/白ひげ/紫衣装/赤マント/金色/黒い輪郭のオリジナルpixel sprite。参考画像は方向性のみ。
- 今後の調整: 初回の停止死亡時間、深い落下の報酬と危険の見積り、柔らかい床の認知。
- 将来Jevに相談: 死因と深さから危険を予測できない区間を特定し、スクロール速度か足場間距離かを切り分ける。

これらは実装意図と検証対象。面白さ・実機親指操作の人間評価は未測定。テレメトリサンプルは合成例で、成功率の根拠にはしない。
