# game018 — 靴とばそ ～Shoe fly in the sky～

- 面白さの核: ANGLE→SPIN→POWERを実験し、靴ごとの物理とMAXボーナスで飛距離を伸ばす。
- 失敗: 短い飛距離、意図と違う軌道、MAXタイミングを逃す。本作の着地は死亡ではなく結果。
- 今回の改善: 赤シャツ/青短パンの少年と蹴りポーズ、足首ひねりとスピン方向の図、説明/練習更新。物理の詳細はmanifest/モデルを参照。
- 操作: Space/タップの3回決定。練習で各段階を試せる。
- タグ: physics / multi-step / distance / absurd。
- UI懸念: 足首の傾きと回転の向き、回転が飛び方に与える影響を手機画面で区別できるか。
- デザイン: 添付少年は服装と蹴り動作の参考。参考画像を背景ごと貼り付けない。
- 今後の調整: 靴タイプごとのスピンの理解、角度/パワーと飛距離の関係、初回と再挑戦のテンポ。
- 将来Jevに相談: フェーズ別離脱と選択パラメータからSPIN理解の問題か入力タイミングの問題かを切り分ける。

想定プレイ時間は設計仮説。人間の面白さ・実機体験は未測定。サンプルJSONは合成イベント。
