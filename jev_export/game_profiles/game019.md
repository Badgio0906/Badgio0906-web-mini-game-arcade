# game019 — 井の中の蛙、大海を目指す ～WELL TO SPACE～

- 面白さの核: 方向×小/中/大のジャンプを選び、狭い足場を登る。100mで井戸を抜け、同一ゲームの後半で風を読んで宇宙へ向かう。
- 失敗: 着地失敗で下へ落ちる、滑る、崩れる足場、風に流される。普通の落下は回復可能な進行後退で、terminal deathとは区別する。
- 今回の実装: 新規2章ゲーム、ジャンプサイズ別の役割、井戸と空の足場、風、独立練習、すぐ遊ぶ導線。
- 操作: 左/真上/右の方向と小/中/大ジャンプ。正確なキーとボタンはゲームの説明と現在のmanifestを参照。
- タグ: jump / rise / pixel-art / animal / hard / precision / space / wind。
- UI懸念: スマホのジャンプ選択を押し分けられるか、風の方向/強さが読めるか、戻された距離が分かるか。
- デザイン: 添付緑pixel frogの緑/大きな目/淡い腹/太い輪郭を反映したオリジナル状態別sprites。苔の井戸から雲/宇宙へ統一したpixel art。
- 今後の調整: 小ジャンプの微調整の分かりやすさ、中/大の着地誤差、風の予告、再挑戦したい戻され方。
- 将来Jevに相談: 高さ別の落下回数、ジャンプサイズ/方向/風を組み合わせた失敗の集中、100m前後の離脱。

現在のcheckpoint/保存/得点閾値はゲームのコードとmanifestを参照。本プロファイルは設計説明で人間レビュー合格を主張しない。
