# 企画05｜囲って、お宝どっさり。 ～LOOP LOOT～

## 企画の核
**「大きく囲め。欲張りすぎるな。」**
空中に浮かぶ宝石と宝箱を、魔法のロープでひと囲み。輪を閉じると中の財宝がまとめて袋へ飛び込み、数と大きさに応じて音が連なっていく。爆弾まで欲張ると、その回の取り分が大幅減。

マッチ3でも落下連鎖でもない、**動く対象を囲う面積と、危険を除く線引き**のアクション。長い線を描くほど偉いのではなく、いま大きく取るか、対象がまとまる瞬間を待つかが判断になる。

## 固定ルール
- 論理戦場480×480、制限55秒、ライフ3。
- 財宝は通常宝石100点、宝箱350点。6波、各波10宝石＋2宝箱＋2爆弾。開始時刻0/9/18/27/36/45秒。
- 波をまたいで物体を無限に積まない。次の波の0.6秒前から残りをフェード予告し、切替時に未取得分を退場。退場加点なし。描画中の輪があれば切替をまたぐ取得は不可として明示取消し、ライフは減らさない。
- 財宝・爆弾は速度25px/秒以下で漂う。盤外へ出さず、反射時に突然加速させない。IDは波をまたいで重複しない。
- PCのdrag、スマホの1本指dragで線を引き、開始点から22px以内へ戻ってreleaseすると輪が成立。最後の短い区間は開始点へ直線で閉じる。
- 制限：線の長さ720px以下、囲み面積1600px²以上、描画開始から1.4秒以内、最大96点。超過時は赤い線と理由を表示し、releaseしても発動しない。
- 自己交差・自己接触・折返し重複辺は無効。始終点が同じになる閉路だけ許可。面積は符号付き面積の絶対値、点判定は一貫したルールで処理。
- 物体の**中心十字**がrelease時の多角形内/境界上なら取得対象。線を引いた時点の位置ではない。爆弾も同じ中心基準とし、見た目の大きさだけで不意に判定しない。
- 再描画のクールダウン0.3秒。取消は0.15秒。描いている間も物体と時計は動く。pointercancel/blurは取消、pause後の古い線は使わない。
- キーボード代替：矢印で仮想ペンを320px/秒、Space保持で描いてreleaseで閉じる。PCマウスとスマホを主要QA、キーボードでも最初の輪を成立させる。

## 得点・失敗・再挑戦
爆弾を囲わなかった時：
`floor(財宝基本点合計 * min(6,2+floor(取得数/4))/2)`。
4個で×1.5、8個で×2、16個で×3。通常の1波供給は12個なので初期版の実到達倍率は最大×2.5。未到達の×3を偽演出しない。

爆弾を1個以上囲った時：
- その輪についてライフ-1だけ。爆弾2個でも同時に2減らさない。
- 対象財宝は取得数には数えるが、点は `floor(財宝基本点合計/4)`。
- 対象IDをその場で確定し、回収アニメ中の二重取得を防止。

55秒まで生存し、財宝36個以上を取得するとクリア。6波で72個供給するので数量上は半分で達成可能。3回失敗でライフ0なら終了。クリア1500＋残ライフ×500。36個目とライフ0が同tickなら失敗優先。

結果には取得個数、最大一囲み個数、爆弾失敗数、スコアを表示。S=クリア/一囲み10個以上/爆弾0、A=クリア/一囲み8個以上、B=その他クリア。

## 配置と最初の快感
最初のサンプル：x=130/175/220/265、y=140/205の8宝石。爆弾は(360,180)など輪の外側。矩形(100,100)→(300,100)→(300,260)→(100,260)を閉じると、周長720で8個をまとめて取得できる。

本番では宝石が小さな群れを作り、爆弾は群れの隣を漂う。完全な待ちゲーにならないよう、9秒ごとに新しい配置へ。爆弾と宝石をピクセル単位で重ねる生成は禁止。安全に数個取る狭い輪と、ぎりぎり大きく取る輪を両立。

## アート・音
主役は成人の宝探し魔女。小さな帽子と大きな袋、ロープを握る手のポーズ。青緑の遺跡、マゼンタの魔法、琥珀の宝石。背景の美しさより、輪と爆弾の中心が最優先。

ImageGen核：
「オリジナル2Dゲーム、成人の宝探し魔女と浮遊遺跡の財宝。青緑の石材、琥珀色の宝石、マゼンタの魔法光。指定された1体/1物体のみ、整ったアニメ塗り、はっきりした外周、透明背景、文字なし。宝箱は閉/開を別画像、爆弾は丸い輪郭と危険の鋲を持ち、宝石と形で区別。」
背景1、魔女通常/大当たり、宝石3形、宝箱閉/開、爆弾、袋。ロープ/中心十字/倍率文字はコード。

閉じた瞬間にロープが締まり、0.2秒ずらした「チャリン・シャリン・ドサッ」。大囲みだけ袋が膨らむ。爆弾はコミカルな煙で、画面全面白飛びはしない。モデルを止めず、回収アニメを次の輪と並行実行する。
