# Game024 · ひとマススネーク / SNAKE

Candidate No.47. Authoritative request: [classic-five REQUEST](../classic-five/REQUEST.md), sections 0–5, 9, 11–19. The user selected **ひとマススネーク** after the requested original title was found in an existing PlayStation minigame. Root owns naming research and publication. Rules `1`, presentation `prototype-1`.

- Standard 20×20 grid, length 3, four cardinal directions, no wrapping. Food occupies a free cell and grows the body by exactly one. Wall/self collisions end, with distinct results; filling 400 cells clears.
- Fixed 4/6/8 cells per second (slow default 4), no acceleration or alternate gameplay mode. Pure seeded model and independent fixed clock; normal frames consume sequential ticks, one queued turn per tick. Queue maximum two, validation against its last direction. Nongrowing tail vacates before collision evaluation; growing tail remains.
- PC arrows/WASD; large touch buttons (minimum 44px). Repeated held keys ignored. Canvas renders rounded green body, small eyes, amber square food and quiet cream/teal panels. Original code geometry; no third-party art or audio. System font preserves all Japanese text without altering shared font subsets. Reference image not received by this author; section3 written visual brief used.
- Optional three entry choices: play, explanation, isolated 8×8 one-food practice. Practice speed 4, no BEST, saved snapshot, completed-run statistics or production RUN/practice events. No success gesture carries into a direction input.
- Pause/Escape, blur, visibility loss, or frame gap over 500ms stop movement. Resume is explicit. A restored snapshot opens paused. Partial fixed tick is retained across ordinary pause; no hidden-time backlog. Resize changes rendering only.
- Existing StorageService/AudioService/TelemetryService/TouchGuards used. Audio is a quiet food tone and saved mute toggle. The single game-specific JSON replacement stores identity/version, speed, seed/body/food/direction/queue/ticks/outcome, clock, run report flag, existing analytics UUID (nullable), BEST per speed, completed runs and clears. Validator rejects duplicates, gaps, invalid food/direction/queue/clock/version/mode/UUID/flags. Storage denial uses current memory.
- BEST updates only on new food progress in a real run. Result report flag and stats persist together, so reloading a result does not repeat statistics. Explicit quit/restart removes the abandoned snapshot atomically. Pagehide only saves and does not manufacture a run_end. Restoring uses the common analytics restore method and does not create another run_start; a missing analytics ID stays nullable.
- Common game_open/run_start/run_end/retry/return/pause/resume and food/BEST milestones only; no frame or whole-body analytics data. External collection is explicitly disabled for this new ID until root confirms the existing Worker registration. Existing Game020 production collection remains outside this scope.

Core loop: plan the next turn, eat, leave space for the longer body, then retry. Skill: direction timing and spatial planning. Score: foods. Failure: wall or own body. No time limit; elapsed seconds are reference telemetry only. Expected play duration and human enjoyment have not been measured. No CREDIT or ads in game logic.
