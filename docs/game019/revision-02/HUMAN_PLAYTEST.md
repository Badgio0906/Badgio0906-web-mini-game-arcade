# Game019 改訂02 — 人間の試遊

**未実施。** 自動モデル／Chromiumの通常キー・多指touch、独立workerの設計・Visual判定から、人間の面白さや実機快適性を合格にしない。公開承認は既にユーザーから受けており、技術検証した版を公開する。

人間が確認する項目：

- カエルのしゃがみと音だけで短／中／長の感覚を覚えられるか。
- 空中補正なしが納得でき、溜めすぎ・不足の失敗から跳び直したくなるか。
- 最初の低梁と20mの横跳び、苔、バケツで前回より上達を感じるか。
- 50m棚で安心し、70m分岐で危険な近道を選ぶ理由があるか。
- 長い落下の前に戻り先を理解でき、10〜27m後退が悔しくても公平に感じるか。
- 100m海→鳥→空のギャグで続きを登りたいか。
- 風の旗／線／HUDと踏み切り風lockingの関係を理解できるか。
- 実スマホの左右＋JUMP長押し、親指の位置、キャンセル、音量、FPS、短い横画面での小さいspriteを確認。
- 200mまでのプレイ時間、学習回数、疲労、総落下表示への反応を測る。

記録欄は、端末／入力／事前経験／プレイ時間／到達高／総落下／どこで何を学んだか／悔しさと理不尽さ／再挑戦意欲。現時点で回答・楽しいという判定・実測想定時間・利用者母数はない。
