# Game019 改訂02 Visual Brief

既存のオリジナル32×28カエルを継承する。参考画像から緑／大きな白目／クリームの腹／太い暗色輪郭／とぼけた横顔を抽象化し、画像の貼付・縮小pixel化・他作品の素材コピーはしない。ImageGenの利用予定は0。小数の縦圧縮に頼らず、溜め1／2／最大を整数pixelの異なる姿勢として作る。ジャンプ左右／真上、落下、着地、滑り、左右風、clearを少数poseで伝える。

井戸の各場所には濡れた石、低い木梁、根、割れた煉瓦、苔、水滴、古い動くバケツ、最後の日光を与える。背景は当たり判定の足場・梁と輝度を分け、装飾を足場と誤認させない。50m等の受け棚は支えと明るい縁で大きさを読めるようにする。上空の風は固定帯の旗と風線、雲の流れで前もって示す。海→鳥→空の短い演出はplay中の世界で描く。

カメラは24px/m、360×480の論理解像度、整数pixelに丸める。上側の次の足場を多めに見せる。本番は正確なPOWER・軌道・正解マーカーを表示しない。練習だけ短いゲージ。下を見るhold操作と現在より下のcatch棚の位置／距離案内で落下リスクを確認できるようにする。

高さ／BESTを主HUD、総落下はpause/resultへ。mobile方向2ボタン＋中央JUMP、全操作44CSSpx以上。320×568と844×390でも画面・操作・説明の読みやすさを実画像で確認する。タイトルの3開始経路を保持し、強制練習はしない。

独立Visualは完成後の実PC／phone画像から判定する。threshold80/100、F/H各12/15。サムネイルを更新するなら実playのcanvasからcropし、原本とhashを台帳に残す。人間の親指・音・体感の判定は未実施と分ける。
