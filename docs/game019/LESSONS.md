# Game019 開発で確認したこと

- 「大ジャンプで高い足場」は強さだけでは成立しない。説明の方向と、モデルの実際の着地点を同時に確認する。直進の説明と右側の配置の不一致は独立レビューで検出し、右方向の実操作テストを追加した。
- 風の予告はスマートフォンでも見える場所へ表示する。hover tooltipだけでは読めないため、現在の風と次の風を別行に示す。
- 落下から復帰するゲームで、落下を死亡として集計しない。run終了、復帰イベント、最高到達を区別する。
- 予測は実際の物理モデルから読み取り専用で計算する。自動入力による到達は操作・物理の検証であり、人間の楽しさを示さない。
