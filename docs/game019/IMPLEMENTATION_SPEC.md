# Game019 — 井の中の蛙、大海を目指す ～WELL TO SPACE～

今回のユーザー指示は [統合依頼](../integration-2026-10-05/REQUEST.txt)。キャッチは「井戸を出たら、今度は宇宙でした。」。Game015の下降・追跡とは別に、着地点を計画する精密な上昇ゲームを追加する。

## Core loop

足場で左／真上／右を選び、小／中／大ジャンプを決める。小は約1mの位置調整、中は約5m、大は約9m。入力後の短いしゃがみは予備動作で、長押しによる強さ変更はない。空中の方向転換を前提にせず、次の足場を先に読む。着地後に繰り返し上る。狭い足場・滑る苔・崩れる木・頭上の壁を見分け、落下したら以前の足場から立て直す。

井戸の100m到達で海を見せ、鳥の演出で空へ続く。空は横風・上昇風・下降風を表示し、ジャンプの強さと方向を再判断する。200mで宇宙到達。100mの海岸床はそのrunの物理的な足場であり、保存チェックポイントではない。新しいrunは必ず井戸の底から開始。中断保存は実装しない。

## 操作と画面

PCは方向キー／A,Dで方向、Z,X,Cまたは1,2,3でサイズ、Spaceで選択中のサイズ。スマートフォンは方向3択とジャンプサイズ3択。9組の同時ボタンは作らず、主要操作は44CSSpx以上。Pause・音・一覧帰還・retryを備える。高さ、最高到達、BESTと風の予告を示す。

初回でも「すぐ遊ぶ／説明を見る／練習する」を選べる。練習は独立したコースで方向、位置調整、3サイズと風を試し、本番のscore／BEST／runイベントを変えない。説明と練習を飛ばしても、実施済みフラグを偽造しない。

## 絵と音

参照画像は方向性のみ。緑の横向きシルエット、大きな目、クリーム色のお腹、濃い緑のアウトラインでオリジナル32×28ドット絵を制作。待機・しゃがみ・小／中／大・落下・着地・風・失敗の9状態。井戸の濡れた石、苔、根、木材から海・空・宇宙へ色と形が変わる。ジャンプ／着地／節目に短い合成音、mute保存。

## 保存・計測・検証

既存namespaceを変更しない。019は独立namespaceにBESTの0.1m単位とmuteを保存。データは端末内に限定。ジャンプ、落下、到達章など実際に発生したイベントだけを記録し、外部Jev APIは呼ばない。

モデル検証は各サイズ、当たり判定、落下復帰、風と到達可能性。ブラウザはPC、390px、320px、横画面の操作・練習・pause・保存・retryとroot/subpath配信。独立Feel/Visual/QAと人間評価を分ける。自動入力が成功しても面白さや実機評価の合格とはしない。
