# Game002 WORKDAY DODGE — Game Feel Review

担当: Game Feel Reviewer（Gameplay Engineer／QA とは別担当）
対象: `game002.html`。Game003 以降はこのレビューの対象外。

## 方法

実際の Chromium で描画を実行し、キーボードの ← / → とタッチ相当入力を通して操作した。1366×900、390×844、844×390 を確認。`__arcadeDebug` は状態・敵・Wave の読み取りだけに使用し、強制死亡・位置変更・早送りは使用していない。1000m まで通常入力でプレイした。

自動操作で測った成功率・生存時間は人間の成績ではない。初心者の平均 RUN 時間、気持ちよさ、再プレイ意向、音の聞き心地、実機 60fps は未評価。Game001 の人間合格を Game002 の合格に転用しない。

## 指摘・修正確認

### P2: 固定速度なのに「最速」と表示する

完走後とタイトルの出社済み記録が「最速 95.9s」だった。現行ゲームは自動の距離進行で、操作で歩行速度を上げる仕組みがない。改善できる速度記録のように見える表示は、リプレイの目的を誤解させる。Main Agent に「到達時間」への変更を提案。修正後の縦・横の実ブラウザで「到達時間 95.9s」と表示され、「最速」がなくなったことを確認した。解消。

### P2: CLEAR 記録を持つ縦スマホの結果カードが切れる

以前の CLEAR 記録と残り 1 CREDIT を保存した状態を設定し、自然な 79m の衝突で 0 CREDIT に到達。390×844 の結果カードは 429.78px、盤面は 358px のため、上の見出しと下の TITLE ボタンが切れた。844×390 では 286.5px のカードが 313px 盤面内に収まった。主スコア・+3 CREDIT ボタンは押せて Stub 後に 3 CREDIT に戻ったが、縦のカード余白／サイズ修正を Main Agent に依頼。修正後、同じ保存状態と自然死亡で再確認。縦カード 280px／盤面 358px、横カード 253.5px／盤面 313px となり、見出し・数値・到達記録・+3 CREDIT・TITLE がすべて盤面内に収まることをスクリーンショットで確認。両ボタンの横並びで、主要リプレイ／補充が優先される。解消。

これは UI 状態の再確認用に保存値を設定したテストで、3 回の自然死亡を行ったという主張ではない。

### 未確定のゲーム性

初回 CLEAR は明確な目標だが、クリア済みプレイヤーがもう一度通勤したいかは未確定。初版では追加スコアモードを要求しない仕様なので、無理に高速化・点数モードを足さず人間の結果を記録する。初見の平均 30〜70 秒も未計測。
