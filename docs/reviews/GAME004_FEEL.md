# Game004 ECHO GRID — Game Feel Review

担当: Game Feel Reviewer（Gameplay／UI／QA とは別担当）
結論: **実行に基づく Game Feel Review は PASS**。Game005 へ進める。人間の記憶能力・楽しさ・再プレイ意向は未評価。

## 方法と限界

実際の Chromium とネイティブ DOM ボタンで、マウスクリック、タッチ、フォーカスしたパネルへの Enter、数字キーを確認した。1366×900、390×844、844×390、320×568 を使用。

高 LEVEL の動作確認は、読み取り専用の `inspection().expectedCell` を参照して正しいパネルを通常入力で押す **oracle 自動プレイ**。位置／LEVEL／時間の変更、強制終了をしていない。この成功を、人間が順番を覚えられる・面白いという証拠にしない。

## 実行観察

| 観点 | 実行結果／判断 |
| --- | --- |
| 最初の 10 秒 | 初期 LEVEL 1 は 2 個の光、準備 0.6 秒、点灯 0.6 秒／消灯 0.18 秒。WATCH「見て覚える」、YOUR TURN の区別があり、入力待ちは時間制限なしと表示される。前方の障害物を避ける／荷物を落とすゲームとは明確に異なる。 |
| WATCH の誤入力 | 表示中にパネル位置を実マウスでクリックし、数字キーを押しても correctInputs 0、alive true、WATCH のまま。スマホの実タッチでも同じ。Playwright の locator は有効になるまで待つため、この確認は座標入力で行った。 |
| 待つ余裕 | スマホの YOUR TURN で約 900ms 入力せず待っても Recall のまま、期待パネル・入力 index が変わらない。隠れた反応期限を設けていない。 |
| 表示と入力 | 大きな 3×3 の固定位置のパネル、数字、明るい点灯と明確な消灯。WATCH 中の disabled ボタンも暗くならず、点灯を判別できた。正解入力は明るく反応し、CORRECT と入力カウントが増える。 |
| 同じマスの連続 | LEVEL 4 で同じマスが続く実例を確認。間に `highlightedCell: null` の消灯状態を実行記録し、同じマスの次の点灯を別の入力として読める。長い 1 回の点灯にまとめられていない。 |
| Pause | 点灯途中で Pause、650ms 待ってもゲーム時間差 0、同じマスが点灯、残り時間を保持。Resume 後に同じ表示の続きを見て Recall へ進めた。320×568 でも Pause でパネル位置／サイズが変わらず、カードの全ボタンが画面内。 |
| 高 LEVEL | マウスの oracle 自動プレイで到達 LEVEL 16、正解総入力 107、ゲーム時間 85.907 秒。長さ 9、点灯 0.28 秒／消灯 0.12 秒の下限を確認。人間の経験者 RUN 時間ではない。 |
| スコア | 到達 LEVEL が主表示、CORRECT が補助。LEVEL 16 の結果は 15 LEVEL を正解して次の 16 に到達した記録であり、16 LEVEL をクリアしたという意味ではない。抽象点数に換算しない。 |
| 失敗理由 | 1 番を押し、期待していた 9 番との不一致で終了する例を確認。押したパネルは赤い面、正解の次のパネルは明るい輪郭で区別し、「押したのは 1・次の正解は 9」と表示。 |
| 正解の再表示 | 失敗後、グリッドを残して正解順序を点灯で再生。結果カードが隣／下に出るため 9 マスを覆わない。順番の数字付き一覧も結果に残る。実際に明るく点灯した再生フレームを確認。 |
| Retry | デスクトップの通常クリックから再開確認まで約 35ms。320×568 では再生途中に Retry をタップして約 62ms で新しい LEVEL 1 へ戻り、500ms 後に古い is-replay／wrong／expected マーカーが残らないことを確認。正解順序の再生終了まで強制的に待たせない。 |
| 保存 | LEVEL 16 の失敗後にリロードし、BEST 16 と残り CREDIT の保存を確認。 |
| タッチ・結果 UI | 縦と横の実タッチで LEVEL 8／35 正解／9 個の順序まで進めてから間違えた。縦の結果時パネル最小辺 74px、横 69.3px。9 個の順序一覧、BEST、CORRECT、TIME、CREDIT、補充／TITLE がすべて見える。 |
| CREDIT／Stub | 残り 1 CREDIT の保存状態を準備し、通常の誤入力で 0 に到達。縦・横で +3 CREDIT を押して 3 に戻りタイトルへ進めた。これは UI 状態のセットアップで、3 回自然終了を実施したという主張ではない。 |
| 視覚方向 | 暗い電子パネル、固定された発光キーと控えめな文字で集中できる画面。Game001 の円形機体、002 の通勤、003 の箱の積み上げを色だけ替えたものではない。 |

## 修正後の独立確認

QA が検出した 320×568 の Pause カードの切れは、UI 担当が RESUME／TITLE の横並びと余白を修正。その後、実際の点灯途中の Pause で独立再確認した。パネルは 260×260px の同じ位置を保持、カード下端 558.44px が 568px 画面内、両ボタンが押せる。追加の Game Feel 修正は不要。

## 人間で判断すること

初期の 2 個を覚える説明の分かりやすさ、LEVEL ごとの長さと速度の体感、短い点灯の疲れ、同じマスの連続の見分けやすさは未評価。現時点で初期の 1 MISS allowance を追加する根拠はなく、仕様どおり 1 回の誤入力で終了する。人間の初回成績が厳しすぎる場合に再検討する。
