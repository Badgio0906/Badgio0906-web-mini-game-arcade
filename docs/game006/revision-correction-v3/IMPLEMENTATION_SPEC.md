# Game006 切り返し改修 V3

ユーザーの第3工程。既存の角度→強さ→走行→任意ブレーキ、枠選択、PERFECT連続、禁断モード、衝突の意味を保つ。

- PCはC、スマホは青い「↶ 切り返し · C」専用ボタン。SPACE/既存赤ボタンは引き続きブレーキ。長押しrepeat、発進時入力持越し、pause中、zero-time切替は拒否。
- 走行開始後・ブレーキ前に、RUN全体で1回だけ曲率符号を反転。ほぼ直進の場合は小さい右曲率0.0014を設定。切替点の位置と車体向きは連続し、その点から新しい厳密円弧で走る。各駐車ごとに権利を補充しない。リトライで補充。
- 予測線、実座標、車体全体の駐車判定、swept collision、縁石、精度、ブレーキ停止点は同じpiecewise円弧モデルを使用。
- 自動の切り返し加点はない。既存の精度・連続PERFECT・挑戦/禁断倍率・ノーブレーキ加点を維持。正確な切り返しなしの駐車も評価。
- 練習を4段階へ。既存角度/強さ、ブレーキ、枠指定に、少し角度を付けて中間で曲率を反転し駐車する練習を追加。練習は本番得点とBESTを保存しない。
- 新BESTは`best-rules-v3`。旧`best`（V1）、`best-rules-v2`は別々に読取り表示、書換・移行・再送しない。

既存の俯瞰自動車美術を保持。赤い制動と青い切り返しを分け、44px以上。切り返しは使用後も「使用済み」を示す。4画面実画像レビューは別途必要。

共通records/gameVersions/board登録はroot統合担当。人間の切り返し判断・テンポ・実機親指操作は未確認。
