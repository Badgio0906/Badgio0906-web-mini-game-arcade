基準ソース：`ad261f9e0cdc6e12b98047d30a30a45f347d62b1`。今回の[指示書](revisions/TITLE_UI_SPEC.md)に基づき、前回のアートを活かして初見の理解、日本語の親しみやすさ、結果の印象を改善します。実装・独立レビュー・最終QAを完了しました。

## 変更前の問題と共通方針

英語ブランドだけでは遊びが伝わりにくく、PCでは大きな説明欄に対してプレイ面が小さくなっていました。日本語を主タイトル、英語を小さな副題として、document title・ヘッダー・開始・結果に表示します。ゲームIDと保存namespaceは維持します。

| Game | 正式タイトル |
|---|---|
| 002 | ゆううつな月曜日 ～WORKDAY DODGE～ |
| 003 | 我が国の建築は世界一ぃ！ ～DROP TOWER～ |
| 004 | あなたの短期記憶、無事ですか？ ～ECHO GRID～ |
| 005 | 右往左往の仕分け術 ～SORT SHIFT～ |

共通の丸みのある日本語フォント「Arcade Rounded」を同梱。M PLUS Rounded 1c Mediumの使用文字subsetを改名して使用します。SIL Open Font License 1.1の著作権・ライセンスを同梱し、原本は配信しません。使用文字705字のWOFF2は106,532 bytesで4本が共有します。日本語の未収録文字はなく、装飾記号7字だけをsystem fallbackで表示します。見出しは太く、本文は読みやすく、数字は揃えて表示。街・建築・実験装置・工場の色と材質を維持します。外部フォントサービスへの接続はありません。

PCでは大きな紹介欄をプレイ面から外し、画面高さに合わせて盤面を中央に確保します。DOMゲームは外枠だけでなくキー・製品・仕分け窓も調整します。canvasは表示サイズを変更し、物理・座標・速度を拡大しません。モバイルの結果と44px以上の操作は別途検証します。

## 005 右往左往の仕分け術：最優先の説明・練習

PLAYで説明へ入り、「今のルールだけを見て左右へ」「丸は左・角は右の例」「途中でルールが変わり左右も逆転」「間違い・時間切れで終了」「←→/A D/左右タップ」を示します。説明から本番へ直接進むか、短い2問の練習を選べます。

練習は別のnative UIで丸→左、角→右。誤答は理由を示して同じ問に留まり、正答で次へ進みます。2問後に明示的に本番へ。練習中は本編を開始せず、CREDIT・自己ベスト・スコア・ゲーム時間を進めません。run ID、run_start、run_endも作りません。RETRYはすぐ本編へ戻り、練習を繰り返させません。

本編のルール・入力条件・時間制限・発送0.23秒・変更0.95秒は維持。新しい条件を強調し、止まった状態で新しい左右を示してから次の荷物へ進みます。結果は正解数・BEST・COMBO・正解方向を保ち、日本語タイトルと短い文言を添えます。

## 002 ゆううつな月曜日：直前回避と段階的スコア

以前の「通過時に直近の移動がある」判定から、実際にその敵の危険な進路を回避した判定へ変更します。

- 移動開始時、同じ敵の水平接触帯±27px内にいること。
- 既存の垂直接触帯±32pxへ敵が入るまでの残り時間が0より大きく、0.65秒以下であること。B/Cの進路変更は完了済みであること。
- 接触帯へ入る前に実際の補間移動で水平帯を脱出し、再進入しないこと。
- 敵がプレイヤーより35px下を安全に通過し、同じwaveの全員が通過してRUNが生存中であること。
- 一波につき一回。安全なレーンでの横移動、待機、早い回避、衝突した回避には加点しません。

移動・衝突の計算、敵の出現・進路・難易度・乱数は維持します。既存の短い表示とSEに、控えめな足元のリングを加えます。reduce-motion時はリングを抑えます。

| NICE回数 | ボーナス |
|---|---:|
| 0〜2 | 100% |
| 3〜5 | 110% |
| 6〜9 | 125% |
| 10〜14 | 145% |
| 15以上 | 170% |

`SCORE = floor(到達距離 × ボーナス% / 100)`。648m・8回なら810点。出社成功と失敗の両方に適用し、HUDには距離とNICE、結果には距離・NICE回数・倍率・SCOREを表示します。

保存は旧`best`を距離BESTとして保持し、点数は新しい`bestScore`に分離。以前の記録ではNICE回数が分からないため、点数へ推定移行しません。出社記録・到達時間・CREDITは保持します。高さ350px以下の横向き結果では、必須の得点4項目と操作を優先して、過去の出社記録の補足行だけを省略します。保存データは維持し、他の画面サイズでは表示します。score/run_end等の主スコアは点数へ変更し、距離・回避回数・倍率を別の属性として記録します。

画面サイズは1920×1080、1440×900、1280×720、1024×768、390×844、320×568、844×390、568×320。エージェントのブラウザを同時実行せず、実装を凍結して独立撮影→QAの順で実施しました。最初の結果probeは最小横向きの任意補足行にも可視性を要求して失敗しました。意図した省略を記録し、必須4項目の可視性、他7サイズでの補足行、元の保存値、タイトルでの可視性を確認する狭い条件へ直し、全32組を再実行しました。ゲームコードの変更・回帰テストの省略はありません。

画像25 WebP（401,502 bytes）は前回の素材を維持。ローカルフォントsubsetとOFLを追加し、原本PNG・TTFを配信しません。既存のJSサイズ基準は変更していません。Phaser共有chunkのViteサイズ警告は既存のものです。
