# 給湯室の落としもの釣り ～LOST & FOUND～ / Game029

独自の会社小物を拾う、終了時間のない穏やかな釣り。Tiny Fishingの具体的素材・画面・コード・配置を使わず、「下降→巻き上げ時の左右回収→帰還換算→RUN内強化」の抽象ループを独自実装した。

## ループと操作

「糸を落とす」→45m/sで自動下降→最深部→25m/sで自動巻き上げ→水面で一度だけ得点／残高換算→強化または次の投。０個回収でも継続でき、強制Game Overや時間制限はない。PCは巻き上げ中だけ←→/A D、スマホは水域内の横ドラッグ。下降中・休憩中の持続入力は巻き上げに持ち越さない。キャンセル／capture喪失は回収確定操作にはしない。

「今日は帰る」は水面でだけ選べ、総得点でBESTを更新する。途中退出はquitとしてRUN破棄。「休憩」と背景化は完全停止し、自動復帰しない。

## 性能と強化

初期100m／3個／幅Lv.1。上限300m／8個／幅Lv.3。価格はそれぞれ55×(購入段階+1)、40×(購入段階+1)、65×(購入段階+1)。糸は+50m、他は+1。最大時は「上限」とdisabled。点はそのRUNだけ、永久通貨なし。score／balance／投数／回収数は10億で飽和し計算を安全に保つ。

## 生成・価値・レア

各投のseedから固定された物を生成し、途中復帰で再抽選しない。28〜48物まで、深度8〜maxDepth-8m、横28〜332の水域。前の投の配列は次の投で交換し、見えない物を描画しない。全世界の蓄積や毎フレーム生成はない。

各物につき2%でマスターキーっぽいもの(160点)、続く3%で金色USB(110点)、残り95%は深度別4種を均等抽選する。浅場(<70m):クリップ8／消しゴム12／ペン18／ケース22。中層(<160m):鍵32／USB40／電卓48／スマホ58。深層:万年筆75／古い携帯85／金色USB110／鍵束95。深層の金色USBは通常4種の1種にも含まれるので、深層での総確率は3%+95%/4=26.75%。これらは設計確率であり実プレイヤー実測ではない。指定投数以内に出る保証はしない。

## 保存と隔離

key `web-mini-arcade:v1:game029:save` version1は現在のmodel、全生成物、捕獲ID、depth／x、強化／残高／総得点、既存observer UUID(なしならnull)、ローカル終了一度ledgerを原子的に保存。midcast／帰還／強化／休憩を復帰でき、必ず休憩から。帰還phaseでは再入金しない。finished／quitはmodel=nullでpagehideから復活しない。保存拒否時はmemory-onlyへ切替し、reload永続性は保証しない。

練習は短い30mでペン・クリップを拾う実モデルの専用投。normal RUN、BEST、通常save、production RUNに混ぜない。ローカル結果UUIDは統計のidempotencyだけに使い、Telemetryには送らない。Telemetryのobserver UUIDは既存サービスで取得し、その既存IDのみrestoreRunする。

参考画像はこのチャット内の視覚方向として受領。原画像のローカルファイル／hashは未提供で、取得済みと主張しない。アイボリー・青緑の水、J形フック、一本の糸、深度目盛り、ペン／鍵／電卓／携帯など独自Canvasシルエットで描画する。文字ラベルなしでも形の判別ができることは独立Visual実画像で確認する。人物不要。
