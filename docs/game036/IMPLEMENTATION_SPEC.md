## ユーザー要件（2026-10-21 作者の直接指示）

- 新しいミニゲームとして「いわゆる落ちゲー」型のパズルを追加する。
- 連鎖や、一気に消すプレイが **比較的容易** で、**爽快感** があること。
- ボーっとしながらも遊べるが、つい「あと1回」と再挑戦したくなること。
- それ以外の設計判断は担当者に一任。

> ID `game036` は最新main（`ac5304fa`）の CURRENT_STATUS にある「次番号36」に基づく暫定。Codex作成の `ASSIGNMENT.md` はない（作者がClaude Codeへ直接依頼）。正式な予約・登録はCodex統合担当が行う。

## Core Loop

1. 2つ1組のおもち（4味：さくら・まっちゃ・ゆず・ソーダ）が6列×12段（＋非表示1段）の盤面へ落ちてくる。
2. 左右移動・回転して置く。同じ味が縦横に4つ以上つながると消える。
3. 消えた上のおもちが落ち、再びつながれば連鎖。連鎖ほど点数が大きく増える。
4. 中央上（3列目・1段目）の×がふさがったら終了。結果画面ですぐ「もう1回」。

## 「連鎖が容易」にする仕組み

| 仕組み | 狙い |
|---|---|
| **落下地点プレビュー** | 影（ゴースト）が着地位置を示し、置けば消える場合は光って「ぽん」、連鎖になる場合は「◯連鎖」と表示。実際の解決処理と同じ関数で全連鎖を事前計算する。考えずに置いても、光る場所を探すだけで連鎖が起きる |
| 4味のみ | 5味より揃いやすく、自然発生の連鎖が増える |
| 最初の2組は3味 | 序盤の土台を作りやすい |
| **こんぺいとう** | 32個消すごとに次の組に星が入る。着地した下（なければ左右→上→盤面で最多の味）の味を盤面からまとめて消す。大きな崩落→連鎖が起きやすい「一気に消す」手段 |
| 全消し | 盤面を空にすると +2000 と専用演出 |

## 「あと1回」にする仕組み

- 1RUNは数分（設計仮説：約4分。実測ではない）。終了→結果→「もう1回」がフォーカス済みで Enter / R / タップ1回で即再開。
- 結果に「BESTまで あと◯点」、最大連鎖の自己最高、毎回変わるヒントを表示。
- スコア・最大連鎖の両方をBEST保存。

## 操作

- PC：← → 移動、↑ / X 右回転、Z 左回転、↓ 押している間ゆっくり、Space / Enter すとん、Esc 休憩、結果画面で R もう1回。
- スマホ：盤面を左右スライドで列移動、タップで右回転、下へはらうと すとん、下へ押し続けるとゆっくり。画面下の5ボタン（◀ ⟲ すとん ⟳ ▶、いずれも44px以上、左右は長押しリピート）。
- 回転は壁蹴り、床蹴り、1列幅の井戸での180°クイックターン付き。

## 速度・得点

- 落下間隔 `max(160, 900×0.88^(LV−1))` ms。LV = 1 + floor(消した数/40)、最大15。
- 接地後の固定猶予 `max(420ms, 落下間隔)`。↓は34ms/段で、接地中に押すと即固定。
- 1回の消去ごとに `消した数×10×連鎖係数`、係数は `n(n+1)/2`（1, 3, 6, 10, 15…）。星の消去も同じ式。星による消去はゲージを増やさない。
- 上限 99,999,999。

## 練習

- 固定の階段盤面とピンクの組。プレビューが「2連鎖」になる場所に置けば完了（出現位置のまま すとん でも成立）。
- 連鎖しない置き方なら盤面を戻してやり直し。
- 練習は score/BEST/run event/保存に入らない（Telemetry は `ignoreEvent` で除外）。
