# 企画02｜金脈、ぶち抜け。 ～VEIN RUSH～

## 企画の核
**「一粒ずつ？ 金脈ごと、いただきます。」**
5列の地底を巨大ドリルで自動掘削する。左右へ進路を選び、つながった金脈へ一度刃を入れると、奥まで亀裂が走り、金塊がまとめて飛び出す。細かい採掘の連打ではなく、先の地層を読んで「どの脈へ入るか」を決める52秒の掘削スコアアタック。

『SUCK & BOOM!』の溜め撃ちではなく、**進路選択→金脈一括回収→高速掘進**が主役。横スクロールではなく上から下へ奥行きが流れる俯瞰断面。小さく掘って終わらず、最下層の巨大金庫を破る終幕を作る。

## 固定ルール
- 盤面5列×80行。1行0.65秒、全80行で52秒。初期列2、耐久3。
- 先4行を常時表示する。論理盤面の幅420、1列84。演出拡大で先読み範囲を変えない。
- 左右キー/A・D、左右44px以上のボタン、操作パッドの左右スワイプで1列移動。1行につき採用移動は1回、次行への予約はしない。移動演出は0.18秒。行境界の0.18秒以内は移動を開始せず「次の列で操作」と表示し、無言で入力を捨てない。
- 行境界で選択セルを採掘。移動入力が行境界と同tickなら、境界前に移動を開始できたかで確定し、遅いフレームで横へ瞬間移動させない。
- SOFT：10点。HARD：耐久-1、点0、セルは壊して進む。GOLD：下記の金脈。CRYSTAL：300点。AIR：点0。色だけでなく亀裂/鋲/結晶形で識別。
- 金脈は4近傍でつながる4〜8セルのveinId。広がりは3行・3列以内、別金脈を連結しない。1セルでも採掘すると全セルを取得済みにし、今後そこはAIR。加点は `100*n + 50*n*(n-1)` を1回だけ。破片の到着は加点条件ではない。
- 取得範囲が画面外ならmini-mapに奥の亀裂を示すが、カメラを急に移動して操作を妨げない。遠い未表示セルを無制限に回収する生成は禁止。
- 最初の金脈は行4/5・列1/2/3の6セル。正しく進路を合わせれば序盤から6個を一気に獲得できる。
- HARDのダメージは行ごとに1回。同一セル再処理なし。耐久0で終了。80行通過かつ耐久>0でクリア、2000＋残耐久×500点。80行目で耐久0なら失敗優先。
- CRYSTAL・金脈・通常土・クリアボーナスを別台帳で管理。通常セルに戻した金脈を再度採掘して点を取れない。

## 出現・難易度
80行を20行ずつ、砂岩→宝石層→機械遺跡→金庫地層へ。速度を途中で上げず、金脈の位置と危険の隣接を変える。HARDで全列塞がない。必ず各行に移動幅1以内でつながる無傷経路を1本以上持たせる。

固定seedの本番。生の一様乱数ではなく、到達可能性を検査したセクションを組み合わせる。CRYSTALの高得点寄り道と、太い金脈を狙う回収経路を分ける。安全経路を画面で正解表示はしない。中央放置が常に正解になる配置にしない。

クリア前に8連鎖級の金脈を最低1回狙える配置を用意する。ただし取得演出の個数を水増しして「8連鎖」と呼ばない。

## 画面・美術・ImageGenブリーフ
主役は成人の女性採掘士、橙色ゴーグルと作業ジャケット、大きなドリル。人物はHUD小立ち絵と通常/成功の2差分。主役機材の回転刃は別パーツ、回転はコード。

生成の共通文：
「オリジナルの高品質2Dアーケードゲーム用素材。巨大な工業ドリルで地底の金脈を豪快に掘り進む世界。暗い群青の地層、山吹色の金塊、発光するシアンの結晶。太く明瞭なシルエットと整ったアニメ塗り。文字・UI・ロゴなし。指定対象は1点だけ、機材と採掘物は透明背景、全体が画面内。小さなゲーム表示でも形が識別できる。」
対象：ドリル本体、回転刃、成人採掘士の基準絵と成功差分、金塊/結晶、3種の地層タイル、最後の金庫扉。タイルの当たり判定はコード格子、絵の凹凸に物理を付けない。

金脈取得時は脈に沿って60ms刻みの亀裂→金塊噴出→スコア束を吸着。刃の火花、低音の掘削音、金属の回収音が重なる。大金脈だけ40msの短いモデル全体停止を許可し、52秒時計も同時停止。1金脈につき1回、通常土ごとに止めない。

## 最初の実装ゲート
絵より先に5×12行のサンプルで、1セル接触から6セルが一度だけ回収され、今後その位置がAIRとして通過することを確認。キーボードとタッチで同じ経路を辿れること。

設計段階の検算：5×80のサンプル盤面に幅1以内の無傷経路があること、最初の6セル金脈の連結性、52秒の計算は確認。**本番生成器・操作受付・面白さは未検証**。

## 固有QA・完成条件
- 全本番seedで無傷経路の探索。追加20seedも有限時間で検査し、詰み盤面を拒否。
- 金脈二重採掘、複数セル同tick接触、未来セルAIR化、耐久0/終端同時をテスト。
- 境界±1tickの左右入力、pause復帰、repeat、スワイプ取消が次行へ持ち越されない。
- 先読み4行を4画面幅で確認。効果中もHARDの形が読める。
- 80行完走、最初の6セル、最大8セルを実操作で確認。放置と狙った経路を比較して得点/被害を記録。
- 描画は近傍最大8行、モデルは有限400セルで足りる。無限地形や破壊剛体は作らない。
- rank：S=クリア/無傷/金脈8個以上、A=クリア/残耐久2以上、B=その他クリア、C=失敗。実装後に達成可能性を検証してから確定。
- 専用分岐 `feature/vein-rush-<task>`。修正範囲は採番後の新作だけ。
