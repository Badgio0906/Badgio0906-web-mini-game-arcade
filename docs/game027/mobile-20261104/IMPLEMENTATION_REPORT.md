2026-11-04 JST。今回のユーザー依頼による実装。公開は統合担当が管理する。

10ショットで終了する独立スコアモードを初期選択に追加。色球1個100点、連続入球で25%ずつ最大3倍、白球スクラッチは150点減点（0点未満にしない）。全色球を入れたら再配置し、残りショットを続ける。CPU・同端末2人の8ボールを選べる。従来から存在する台ドラッグ照準を主操作として説明し、52px高のパワー操作を拡大。短い横画面では44pxと2段の操作配置でフッター上へ収める。

- 新BESTキー `web-mini-arcade:v1:game027:challenge10:r1:best`。8ボールの対局・勝敗集計へチャレンジを含めない。新規の外部ランキング送信なし。
- 既存rules1 snapshotへ検証付き任意 `challenge` を追加し、旧snapshotをそのまま読み込める。進行中チャレンジも停止・再読込・明示再開できる。
- 練習はチャレンジ・本番統計から独立。CREDITが有効な設定の場合のみ通常対戦2・チャレンジ1を開始時に消費。現行の無制限設定を有効化しない。
- 描画・物理・CPU・8ボール判定・既存音源は維持。追加画像・外部素材なし。
