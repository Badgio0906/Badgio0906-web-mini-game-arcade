# 素材・表現・名称

古典8ボールの一般的ルール、番号1–15・ソリッド／ストライプ・6ポケットを題材に、独自TypeScript物理／判定／UIとCanvas形状／CSSで実装した。外部サイトの素材、音源、コード、特有UIは流用していない。音は既存AudioServiceの短い合成音。サムネイルは実画面から採用する。参考画像は配色・見通しの方向性として使用し、画像の球配置や装飾を抽出していない。

公開名はユーザー指定の「ひと息ビリヤード ～EIGHT BALL～」。特定アプリ名「8 Ball Pool」は使わない。ルールと具体的表現の区別は権利検討の参考であり、日本の法的クリアランスや権利ゼロの保証ではない。一般的な8ボールの簡略ルールであり完全公式準拠の表記をしない。
