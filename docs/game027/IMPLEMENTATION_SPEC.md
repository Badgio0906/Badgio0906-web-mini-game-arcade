# Game027 ひと息ビリヤード ～EIGHT BALL～

100ガレ版8ボール。時間制限なし。6ポケット、白球＋1–15。CPU3難度／同じ端末2人／任意の一球練習。暗緑フェルト・コード描画の木枠・独自球表示・アイボリーUI。ユーザーの参考画像の配色とテーブルの見通しを参考にし、配置や素材を抽出／流用しない。

判定の正本は実装前に書いた [SHOT_RULE_TABLE](SHOT_RULE_TABLE.md)。全球停止後に一度だけ、ショット開始時の合法対象と全入球集合から判定。最初の接触順のみ物理時間に依存し、入球のイベント順ではグループや勝敗を変えない。公式競技完全準拠とは表示しない。

球モデル900×450、半径12、固定120Hz、最大移動量を半径0.35倍に制限する適応サブステップ。等質量衝突、減衰クッション、転がり摩擦、低速停止、最大20秒の停止安全策。ポケットの実際の開口とクッション判定を一致。CPUは合法対象とは分離した近似カット狙いと難度別誤差／反応待ち。

台上ドラッグで照準。白球から最初の接触までの点線（反射先全経路を見せない）。矢印／Shift矢印で微調整、パワースライダー、明示ショット。キャンセル／capture損失はショットにしない。配置時は仮白球位置→明示確定、重なり／ポケット／枠外は拒否。

狭い縦画面は台全体を90度回転して収め、球番号を正立表示する。world→screenと入力の逆変換は同じcameraモデルを使い、物理寸法／ラック／球半径は変えない。狙いの最初の球番号・グループをHUDでも明示。共有の同意フッター64pxを変えずに、自分のメニューと台をその上へ収める。

画面世代とfresh pointerdown対象で旧ジェスチャーのcompatibility clickを拒否。Enter／Spaceはrepeatとheldを区別し、画面切替後のkeyupを新ボタンへ転用しない。キーボード／支援技術のfresh detail0 clickは維持する。

保存はnamespace game027、原子JSON。全球の位置・速度・入球・最初の接触・開始合法対象・ブレイク・手番・設定を保持し、再読込は手動再開待ち。非表示からcatchupしない。明示退出でsnapshot/currentを消し、その後pagehideで復活させない。nullable既存observer UUIDと独立したlocal結果IDを区別、勝敗・統計は一度だけ。保存拒否後は最新memoryを読み、古いbackendを読み直さない。

練習は本番RUN／結果統計と分離。既存Telemetryに意味のあるshot/foul/pocket/group_assigned/win、位置の毎フレーム送信なし。外部送信はrootのWorker登録確認まで停止。広告／CREDIT／GA4／既存ゲーム・保存は変更しない。

練習由来のproductionイベントは、Portal戻り／page_exit／自動エラーも含め、root所有SDKの任意ignoreEvent callbackで除外。CPU結果はwinner0=win、winner1=loss、2人対戦はwinner付きwin。ファウルUIは日本語を保ち、Telemetry理由は既存安全フィルタへASCIIコードを渡す。保存の壊れたJSON・意味的に不正な内容・過大内容はmemoryOnlyへラッチし、その後の古いbackend状態を復活させない。
