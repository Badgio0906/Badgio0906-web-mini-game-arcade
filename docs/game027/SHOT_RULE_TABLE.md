# Game027 — ショット判定表（実装前の正本）

2026-10-08（日本時間）。これは100ガレ版8ボール。完全な公式競技ルール準拠とは表示しない。最後の8番はどのポケットでもOK。ブレイクでの4球クッション条件、コールショット、ショット時間制限は採用しない。

全球が停止してから、一度だけ判定する。ファウルは白球スクラッチ、接触なし、最初に合法球以外へ接触、接触後に入球もクッション到達もなし。合法対象はショット開始時の残球から決め、途中の入球で8番を合法化しない。

|開始状態／同一ショットの結果|確定結果|
|---|---|
|ブレイクで8番のみ入る、白球は残る、合法接触あり|8番を空いたラック側位置へ戻す。グループ未決定。手番継続。|
|ブレイクで8番と白球が入る|8番を戻す。スクラッチで相手のボールインハンド。グループ未決定。|
|ブレイクでソリッド／ストライプ両方が入る|球は落ちたまま。グループ未決定。ファウルがなければ手番継続。|
|未決定の通常ショットで両グループが入る|合法なら入った球のうち番号が最小の球のグループを手番側へ割当。これは順序に依存しない100ガレ版簡略化。手番継続。|
|自分の球と相手の球が入る|合法なら自分の球が入ったので継続。相手球も落ちたまま。ファウルなら相手のボールインハンド。|
|最後の自分の球と8番が同じショットで入る|開始時には自分の球が残っていたため8番早落ち。手番側敗北。|
|合法な8番が入った後、遅れて白球が入る|停止まで待ち、スクラッチにより手番側敗北。先に勝利を表示しない。|
|合法な8番のみ入る、他のファウルなし|手番側勝利。ポケット指定不要。|
|未決定時の通常ショットで8番が入る|手番側敗北。|
|自分の球のみ正しく入る|継続。|
|相手の球だけ入る、最初は合法対象に接触|ファウルなしなら手番交代。相手球は落ちたまま。|
|入球なし、合法対象への接触後クッションあり|手番交代。|
|入球なし、接触後クッションもなし|ファウル、相手ボールインハンド。|
|ボールインハンドで他球に重なる／有効範囲外／ポケット内|配置不成立。白球の位置を変更せず、配置状態を保つ。ペナルティなし。|

8番の勝敗はファウルと開始時の合法対象を最優先。ブレイク8番だけは勝敗対象外で戻す。入球リストは集合として扱い、入球順を変えても判定が変わらない。最初の接触対象の記録は実際の物理的な接触順である。

ファウル後はテーブル全体の有効範囲内へ白球を置ける。配置の重なりは球半径2個分の距離で検査し、置いた後に照準とショットを行う。練習は本番の判定／記録へ混ぜない。
