# 企画06｜反射で全滅！レーザーディスコ ～MIRROR DISCO～

## 企画の核
**「鏡を二つ、カチカチ。次の瞬間、全滅。」**
照明係の成人女性DJが、鏡を回してレーザーをステージ中へ通す。正しい経路を作って発射すると、反射音が連なり、複数のドローンが一度に弾ける。60秒で12ステージを制圧する反射アクションパズル。

じっくり考え続けるパズルではなく、2〜3枚の鏡を見て**最小の変更で一斉撃破**する。短い成功を次々積む。花火033と違い、火力を溜めず、光の進路を自分で作る。

## 固定ルール
- 7×7の整数格子。列x/行yは0〜6。盤は420×420論理px、セル60。
- 各面は鏡2枚または3枚、標的3〜4個、左からの入射点1個。標的は固定。鏡は `/` と `\` の2状態だけ。
- 鏡をtap/click/キーボード1〜3で90度反転。1gestureで1回。長押しで反復しない。
- FIREボタンまたはSpaceで発射。残弾24、制限60秒。全12面の標的を倒すとクリア。弾0か時間切れで未達なら失敗。最後の1発で全滅した場合はクリア優先。
- 1発のレイはセルごとに進む。`/` は `(dx,dy)→(-dy,-dx)`、`\` は `(dx,dy)→(dy,dx)`。境界外、同じ(x,y,dx,dy)再訪、または64セルで終了する。
- 標的を貫通する。1発内で同一標的を何度通っても1回だけ撃破。失敗発射で倒した標的はその面で倒れたまま。誤射の取り消し・残弾返還はしない。
- rayの論理解決は発射時の鏡状態で一度だけ行う。描画は通過順に伸ばして0.4秒以内。演出中は鏡/FIREをロックしてモデルと描画の矛盾を防ぐ。
- 全滅後0.25秒で次面へ。60秒時計はこの演出中も進む。成功のたびに数秒待たせない。pauseだけ停止。
- ゲーム中は最初の鏡までの短い入射予告だけ表示し、最終正解経路を常時見せない。練習1面では全経路表示を選べる。

## 得点・報酬
- 標的1個200点。面の1発目で倒した標的は×2、それ以降は×1。
- 面全滅ボーナス：1発なら400、2発以上なら100。
- 全面クリア：残弾×200＋残秒floor×100。
- 反射数の追加加点はしない。無限反射ループで点を増やせない。
- 3面連続一撃全滅でステージ背景の照明を1段強化、6面連続でDJカットインを短く表示。次の鏡を隠さない。
- S=全面クリア/全12面一撃、A=全面クリア/一撃9面以上、B=その他クリア、C=未達。

連続命中の「キン、キン、ドガーン」、光が折れて走る気持ちよさを重視。標的が4個なのに20撃破などの架空カウントは出さない。大量の装飾片は得点対象と区別する。

## 美術・ImageGenブリーフ
成人女性DJ兼照明技師、短いジャケットと大きなヘッドホン。白/紫の主役、背景は黒/シアン/赤のレーザーライブハウス。鏡は角度が読める厚い外枠と反射面。

生成核：
「オリジナル2Dアーケード用のネオンライブハウス。成人女性DJ照明技師／指定の小型ドローン／レーザー装置を1点ずつ。可愛いがプロらしい自信のある表情、明瞭なシルエット、整ったアニメ塗り。人物と機材は透明背景。鏡の方向記号、レーザー、数字、文字、UIは描き込まない。」
主人公通常/成功、背景1、標的ドローン、砲台、鏡外枠。実際の反射線はコード。360度画像生成や3D化は不要。

## 実装ゲートと固有QA
最初に画像なしで12面ray tracerと全状態探索を作る。ゼロ長方向、無限ループ、レイ1発1標的、発射ロック、最後の残弾を確認。12面全部に1発クリアの入力列があることをassertする。

ブラウザでは最初の3面と最後の面を通常tap/keyで実行し、さらに12面を通した実入力完走。全標的削除の状態書換えは禁止。320pxでも鏡の実タップ域を44px以上に保つため、盤面とUIは分ける。

本作は描画/反射計算とも軽い。12面完了のモデル予算は24発×64セル程度。過剰な物理エンジンや毎フレーム経路探索を追加しない。遊びやすい難度かは未確認なので、初見試遊で読みづらさを確認してから速度を調整する。
