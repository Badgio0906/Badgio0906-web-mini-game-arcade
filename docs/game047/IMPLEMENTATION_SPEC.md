# 企画08｜雪玉、規格外。 ～SNOWBALL XL～

## 企画の核
**「最初は雪の粒。最後は城ごと。」**
小さな雪玉を転がし、雪のかけら→雪だるま→玩具スノーカー→氷の塔を巻き込んで巨大化する。さっき避けていた物が、いまは一瞬でバラバラになる。最後は中央の巨大な氷城へ体当たり。

自動レーン回避ではなく、**自由に走り回り、今食べられる密集地を選ぶ**成長型スコアアクション。チルな雪景色ではなく、スピード線・低音・大量回収が主役。人や動物は巻き込まず、対象は雪・氷・玩具のみ。

## 固定ルール
- 世界960×960、論理viewport480×480。主人公は雪玉に乗った元気なペンギン整備士。初期位置(120,120)、質量M=16、ライフ3、制限65秒。
- PCは矢印/WASD、マウスdragの相対スティック。スマホは下部仮想スティック。方向だけを決め、吸引ボタンや攻撃ボタンは無い。斜め速度は正規化。
- 移動速度 `clamp(200-1.2*sqrt(M),120,200)` px/秒。
- 論理半径 `min(58,12+0.7*sqrt(M))`。見た目の拡大は短く補間してよいが、判定を数秒遅らせない。今の判定輪郭を薄く表示する。
- カメラは追従。M=220/600で少し引く演出を許可するが、全端末で同じ論理視野を使う。UIサイズは縮めない。

|対象|個数|必要質量|取得質量|基本点|
|---|---:|---:|---:|---:|
|雪のかけら|28|0|4|40|
|雪だるま|10|80|20|150|
|玩具スノーカー|8|220|50|400|
|氷の塔|6|600|160|1000|
|大氷城|1|1500|0|5000|

対象の必要質量を満たして接触すると取り込む。満たさない物は軽く押し戻すがダメージなし。条件は形の違い、ロック記号、必要段階で示し、色だけで判断させない。

各tick開始時のMで取得候補集合を決め、その集合をまとめて確定する。そこで成長したため新しく取れる物は次tickに判定。同じtick内のobject配列順で成長/得点が変わらない。

危険物は固定の赤黒い尖った氷3〜5個だけ。これはどれほど大きくなっても取得不可。接触でライフ-1、1秒無敵、短い押し戻し。背景の氷の絵と区別する。3回で失敗。

65秒以内に大氷城を取り込めばクリア。城撃破とライフ0が同tickなら失敗。取得済みIDは復活しない。時間切れでも正式結果としてスコアを表示する。

## 回収と得点
1秒以内の連続取得でcombo+1、間が空いたら1へ。`floor(基本点 * min(30,10+combo-1)/10)`。複数同tickの対象はID順で点を算出し、質量の閾値判定は上記のtick開始時基準と分ける。

大氷城の5000は倍率対象外。クリアで残り秒floor×100＋残ライフ×500。
結果は最大質量、取得物内訳、最大combo、クリア時間。S=城撃破/無被弾/残り10秒以上、A=城撃破/残ライフ2以上、B=その他クリア。

## ワールド設計と検算
雪は開始区画、雪だるまは隣区画、玩具は中央回廊、塔は外周、氷城は終盤区画へ。ただし巨大化しても戻れる通路を確保する。最終半径58の直径116＋余裕24=140pxを主要通路の設計目安にする。

全供給を取る場合の質量は16→128→328→728→1688。5本の塔までで1528となり、6本すべてを要求しない。この**数量条件は検算済み**。実際の配置の通行可能性・回収順・65秒到達はまだ未検証。

固定seedのコンパクトな地図。生成器や無限マップは作らない。時刻付きの通常操作経路を作り、140px通路で曲がれることを実モデルで確認する。成長した瞬間に壁の内側へ入り込む場合は最小押し出し、取得の取消やteleportで誤魔化さない。

## アート・音
ペンギン、白い雪玉、アイスブルーの城、鮮やかな赤い玩具。玩具都市のミニチュア感と、雪玉の大きさでスケール変化を見せる。氷城の破壊は破損差分＋制限数の破片で作り、1000個の剛体を生成しない。

ImageGen核：
「オリジナル2Dアクション用、俯瞰斜めの玩具雪国。指定のペンギン整備士／雪だるま／玩具スノーカー／氷の塔／大氷城を1点だけ。厚みのあるアニメ調、雪の柔らかさと氷の硬さ、明瞭なシルエット、透明背景、全体が切れない。UI・文字・実在ブランドなし。」
必要：地面タイル1、ペンギン通常/歓喜、雪玉テクスチャ、取得物4系統、城通常/破壊、危険氷。物体の論理質量は絵から推定せずデータで固定。

雪はサクサク、玩具はカラカラ、塔は重いガシャーン。段階アップで低音とカメラの引きを同期。最後だけ短い全モデル停止50msを1回許可し、城が砕けるまでの待ち時間は1.2秒以内。

## 固有QA
- 質量79/80、219/220、599/600、1499/1500、半径上限と速度下限。
- 同tick大量取得、配列順変更、再接触、成長時の境界押出し、危険物との同時接触。
- カメラと照準/スティック座標の変換、壁へ向かって保持、resize/横画面、repeat/cancel。
- モデルで65秒内の城到達経路を確認後、実pointer/key入力で再現する。総資源が足りるだけで到達PASSにしない。
- idleでは進まず、雪だけ集め続けても城を取れない。成長ごとに対象が変わる理由が画面で分かる。
- 世界物体は60以下、空間分割または少数の円判定で十分。3D/巨大physics engine不要。
