# Game023 スマホ・5問ラウンド改修

2026-11-04 JST。ユーザーの「1画面のかな入力・5問連続・ミス表示と連続正解得点・語彙増量」を実装。

清音46キーをスマホで6列×8行に収め、44px高のタップ領域を保持。上部の見出し・余白を縮め、320×720 / 390×844の両方でキー最下部663px、下のヒント・遊び方も表示できる。清音／濁音／小文字の区分と既存キーボード操作を維持する。

5問を1ラウンドとして問題番号・合計得点・連続正解数・ラウンド末の正解数と端末BESTを表示。各問8ミスまでで、失敗しても次の問題へ進める。正解時は100＋残りミス回数×20＋連続正解数×50点。ヒント使用時は半分。失敗した問題は0点で連続正解が切れる。第5問の結果から再挑戦すると新ラウンドになる。制限時間は設けない。

語彙は180→330語。元180語のID・読み・カテゴリを保持し、食べ物／動物／物／自然／場所へ各30語追加。全部3〜8文字、重複なし、入力可能かなのみ、短いオリジナルの手がかり。全語を一巡するまで同じ語を再出題しない既存ルールを保持。

保存は既存question JSONに任意の検証済みroundを加える。旧question・ledger・reported・rules1互換を維持し、結果再読込で加点しない。ラウンドBESTは別キー `fiveWordsV1Best`。既存の語数記録と新ラウンド点数を混ぜない。練習はラウンド得点・BEST・本番保存へ反映しない。広告・CREDIT・解析同意設定は変更しない。
