# Game018 lessons

- 固定物理軌道と演出の再生時計を区別する。高速度の到達イベントは、ワールド位置に忠実でも1〜2フレームで画面外へ消える。実地点の短い演出holdで見せ、物理結果や得点を捏造しない。
- 追尾中心のviewport内判定だけでは視認性を証明できない。最前面のバナー・背景との重なりを実画像で確認する。
- スマートフォンのtap完了はnavigation完了と同じではない。waitForURL／次画面のDOMを待ち、離脱中のRAFキャプチャにwatchdogを置く。
- data属性のselectorはボタンclassやmenu scopeへ限定する。親appの状態属性まで数えると5靴が6件になる。
- 320px／short landscapeの選択・結果は主操作を優先し、必要ならその画面だけ背景Canvasを省く。44pxの開始・Retry・靴変更・帰還はviewportと祖先clipの両方で確認する。
- Jev riskはビルド未検証・軽微な工程問題を公開危険へ上げやすい。実際のユーザー影響と定義を独立レビューし、API値から正解を作らない。
- Git認証、Actions成功、公開URLの通信許可、公開DOM、実機の面白さは別工程。ネットワーク設定が起動済み環境へ適用されない場合も、成果と再開手順をRepositoryに残す。
