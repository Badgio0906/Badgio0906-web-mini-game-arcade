# 1ミリカーリング — IMPLEMENTATION SPEC

第4工程52〜61章に基づくCanvas固有ゲーム。相手AIなしのスコアアタック。3エンド、各最大3投。各エンド開始時の青い相手石は2個、配置は3通り。赤が自分の石。中心への寄せ、相手石の押し出し、手前のガードを組み合わせる。

マウス/タッチで氷面を押し、進みたい向きと逆に引いて離す。12 model px未満と上向きへの引きはキャンセル。190pxで最大パワー。ガイド線は衝突前の予測方向と停止距離、パワーバーで強さを示す。矢印で方向/強さ、Space投球も使用できる。投球中の追加投球は禁止。休憩/blur/hiddenは全石を止め、明示再開。44px以上の主要ボタン。

480×760氷面、120Hz固定刻み。全石半径18、同じ質量・摩擦150px/s²・反発0.94。円形衝突は位置分離と近づく相対速度への等質量impulse。氷面の外へ出た石は除外。速度に比例しない一定減速なので引きの強さから停止距離を学べる。最大パワー直進は中心を飛び越す。

独自採点：中心距離dの自分石ごとにround(1000×max(0,1−d/128))、相手石を中心半径146外へ出すと各150、中心付近の自石の手前（y295〜600、x差55未満）に別の自石でガード150、中心内の石を確保して未使用の投球を残せば1投100。中心に寄せたエンドが続くと2回目200、3回目400追加。公式競技採点と混同しない説明を常時表示。最大検証値15000点。

「ここで採点」で少ない投球の成功を確定でき、3投後は自動採点。3エンド完了時のみtotalを個人BEST/records完了へ渡す。途中退出/練習はBESTへ加算しない。練習は相手石なしの1投を繰り返し、中心内へ寄せる通常投球が成功条件。

保存は専用stateキー、rules1。全石の位置/速度/除外状態、エンド/投球/内訳、total、連続好配置、run ID、reported、BEST/runsを保存。飛行中でもpause/reloadで全世界を復元し、終了の二重加算を防ぐ。失敗storageはメモリ継続。旧ゲーム保存のmigrationや変更はない。
