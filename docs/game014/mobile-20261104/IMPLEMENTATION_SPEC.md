# Game014 スマホ改修仕様

2026-11-04 JST。元のキャラクター／手のポーズを保持したnative版で、指ハートのタイミングを採点する。25回を5段階のスピードで狙うが、違うポーズの入力で即結果となり1プレイを区切る。

- 指ハートの表示時間の中央44%でぴったり100点、それ以外の有効な指ハートでまあまあ60点。25回の最大2500点。
- 5成功ごとに表示間隔650/550/450/350/250ms。成功後650msは入力を無効にして、押しっぱなし・連打による二重得点を防ぐ。
- ランクはS2300以上、A1800以上、B1200以上、C600以上、Dその他。終了後の得点と成功数、再挑戦を表示。
- 練習は2成功で終了、ミスは再練習できる。練習はBESTを保存しない。
- 全7ポーズを読み込み／decodeしてから開始。表示中のdecoded画像だけを判定対象とし、通信遅延による表示と判定の食い違いを防ぐ。
- 非表示／blur／回転／pagehideは一時停止、復帰には再開操作を要求。非同期の開始中に離脱した場合は開始を無効化。
- `game014.mobile.v2.best` は整数0〜2500の別保存。旧Godotの成功数25上限の記録へ点数を送らない。旧PCK／WASM／game.html／旧保存を保持。
