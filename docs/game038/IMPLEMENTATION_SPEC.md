# Game038 6万分の1 ～ONE IN 60,000～ — 実装仕様

## ユーザー要件（2026-10-21 作者の直接指示）

- 『80億分の1』のVTuber版として「6万分の1」を作る。基本仕様は80億分の1を踏襲する。
- 違いは、最初に**目指すVTuberの名前を自由入力**し、**目指すジャンルを選択**してスタートすること。
- 世界のVTuber人口は約6万人という前提で企画する。
- 目指すジャンルは方向性にある程度影響するが、その通りになるとは限らない。

> ID `game038` は暫定。`game036`（PR #8 と #16）と `game037`（PR #9）は未統合のdraft PRで使われているため避けた。Codexの `ASSIGNMENT.md` はなく、正式な予約・登録はCodex統合担当が行う。

## 6万人の前提とジャンルの扱い

- 「6万人中◯位」は最高登録者数から求める。分布はゲーム上の仮定：100人以上58%、1,000人以上24%、1万人以上6.5%、10万人以上1.2%、100万人以上0.09%（約54人）。実データではないことを遊び方に明記。
- **ジャンル**：目指すジャンルは初期の傾向（affinity 30、ほかは3〜11）と、わずかな適性ボーナス（+0.15）を持つ。各キャリアには**ジャンルごとの隠れた適性（0.45〜1.7）**があり、毎月「視聴者に届いた配信」がaffinity×適性²で抽選されて傾向が動く。決断の選択肢もジャンルの傾向を動かす。表示上の「いまの方向性」は傾向が最も強いジャンル。
- おまかせで2000人分を回した結果、最終的な方向性が目指すジャンルと違う割合は約25%（`tests/unit/game038-model.test.ts` で10%超・維持50%超を保証）。

## 成長・終わり方

- 月の登録者増 = (登録者+20)×率×運 + 所属の流入×運 − 登録者×2.6%。率は配信力・つながり・重点・ジャンル適性・本業・楽しさで決まり、登録者が多いほど頭打ちになる。まれに切り抜きがバズる。
- 1,000人で収益化。月収・貯金は表示用で、専業で貯金が尽きると引退しやすくなる。
- 楽しさは毎月平均へ戻り、伸び悩むと下がる。体と心は重点で増減する。
- 引退の判断：毎月の確率（体と心・楽しさ・伸び悩み・登録者が少ない・貯金で上下）。卒業・無期限休止はプレイヤーに「続ける／休止／終える」を問う。体調・契約終了・暮らしの変化は問わずに終わる。12年（144ヶ月）で区切り。
- おまかせ2000人分の結果：活動期間の中央値64ヶ月、最高登録者の中央値769人、1,000人以上44%、1万人以上9.8%、10万人以上0.7%。

## 練習・保存・境界

- 練習：固定seedの個人勢・学生「練習さん」（雑談志望）で半年。決断は通常どおり、問いかけ・引退なし、記録・保存・計測なし。終了後に本番の設定画面へ。
- 保存：`web-mini-arcade:v1:game038:state`。進行中の活動（決断の途中も含む）、直近10回の記録、最高順位、回数、前回の名前・ジャンル。再読込は休憩画面から再開。不正値は破棄、保存拒否時はメモリで継続。
- ユーザー入力（名前・ひとこと）はすべてHTMLエスケープして表示し、名前からは制御文字と `<>` を除く。
- 実在のVTuber・事務所・配信プラットフォーム名は使わない（「銀の盾」「スーパーチャット」は一般名詞として使用）。
- CREDIT無料（未接続）、広告なし、Telemetry `remoteCollectionEnabled:false`、記録共有は未接続。
- ダイアログ表示後450msは入力を無視（再生中のタップが、直後に出た決断ボタンを押さないため）。
