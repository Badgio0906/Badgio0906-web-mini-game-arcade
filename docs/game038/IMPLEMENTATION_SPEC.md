# 雨を避けて帰ろう / RAIN UMBRELLA RUN — 初期仕様

2026-10-18 JST。新作予約game038。main9e96d55には035まで、036はPR8未採用、037は今回の正式採用候補。既存017のルート描画/雨避けと異なり、実時間の3ライン・動く傘への乗換え・属性得点を核にする。017のコード/ルール/背景bytesは変更しない。

## ルールと今回の決定

- 90秒/180mの自動前進で家へ。上/中/下の3ライン。上下またはW/S、3つの44px以上のボタン/ラインtap/上下swipeで変更。左右微調整は初期版では採用しない。
- 直接雨に濡れた累計が3.000秒で失敗。傘でゲージは減らず、増加だけ止まる。ゴールと濡れ限界が同時なら失敗を優先。
- 主役は日常着の帰宅者。閉じた傘を持つ（壊れた/使わない理由は仮設定）。自分の傘で常時無敵になる絵を避ける。開いた傘は通行人だけ。
- 保護は同じラインかつ足元xが傘中心の半径内。円い足元マークが実保護幅を示す。ライン移動は即時のゲーム判定、描画だけ短く補間する。移動中に別ラインをまたいで保護されるとは扱わない。
- 1人の傘で最初に保護された時だけ得点。出入り連打で再加点しない。重なった傘は距離が最も近い相手（同値はID順）を優先。
- おねぇさん+150、こわもて−120、会社員男+20/女+30、学生+50、老人+10、親子+90、レア+250。仮バランス。得点は負にもなる。美醜で人格を断定する設定ではなくこのゲームのリスク/リターン役割。
- 同方向の案内用通行人は約3秒ごとに交代し1.6秒重なる。常に完走可能な傘の連鎖を用意。反対方向/追越す一般通行人も生成し、安全と点数の選択肢を増やす。人数は最大40程度、出入りで破棄。routeの固定seedは初期QA用で、ランダム不可能配置を作らない。
- 練習は短い約9秒、別ラインの傘へ実際に1回以上乗り換え、濡れ限界未満で到達して成功→開始を別gesture。放置完了は不可。練習はBEST/本番score/外部eventに影響しない。再訪の即開始と再練習を用意。
- title/help/practice/play/pause/result/retry。Escape/休憩/blur/hiddenで時計を止める。キーrepeatと画面を跨いだ押しっぱなしを消費しない。
- BEST/muteはgame038専用キーだけ。保存拒否はmemory fallbackと非永続表示。既存キー/共通CREDIT/広告/Analytics/ネットワーク送信は使わない。
