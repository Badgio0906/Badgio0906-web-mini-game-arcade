# 雨宿りリレー / Rules 2

旧見下ろし描線方式から横視点の雨宿りへ。旧RainRun/描画/単体23件は比較用として保存。

左右／A・Dで移動、Space／専用ボタンでダッシュ（0.48秒、再使用1.7秒）。5種の安全地帯（軒下・バス停・木陰・アーケード・屋根）11地点先のゴールへ進む。雨の周期は小雨→大雨→突風→小雨、変化前1秒を予告、風向きも表示する。屋根内の緑枠は回復。濡れ0～100、100で失敗。少量接触では失敗しない。

スコアは新しい前進距離×乾き係数、初到達の安全地帯、乾いた連続到達、低い濡れ具合で突破した雨の強さ。後退と再到達による得点稼ぎは不可、放置は加点0。練習は最初の屋根まで実移動、濡れ切ったら再開し得点0・本番記録除外。

保存は `web-mini-arcade:v1:game017:bestRelayV2`。旧 `best` を上書きせず表示。共有カタログ／recordsの比較版更新はMain担当。
