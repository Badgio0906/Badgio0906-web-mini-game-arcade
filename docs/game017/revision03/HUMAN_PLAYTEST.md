# 表示014の改良候補・試遊手順

人間による評価、Windows/スマートフォン実機、Safari、音の聞き取り、連続FPS測定は**未実施**。Linux headless Chromiumの自動キー/タップ検査と区別する。正式採用・main公開も未実施。

## ローカルで開く

この候補を含むcommitをcheckoutし、repoのルートで次を実行する。通常のproduction buildへの登録はしていない。

```sh
npm ci
npx vite --config tests/game017/revision03/vite.config.mjs --host 127.0.0.1 --port 4938 --strictPort
```

Windows Chromeで `http://127.0.0.1:4938/game017-revision03.html` を開く。画面上部の「014 · RAINSHIFT 改良候補」を確認する。旧正式ページは`game017.html`。localhostの記録は公開サイトとは別originになるため、公開サイトに保存済みのBESTがここに自動表示されなくても消失を意味しない。

## 確認する操作

1. 遊び方→練習へ進む。上下キー/W/S、または3つのラインボタンで別の傘へ1回以上移り、9秒の練習を終える。
2. 本番で傘を渡り、累計3秒未満の濡れ時間で90秒/180m先の家を目指す。属性による加減点、保護範囲と濡れ表示の分かりやすさを確認する。
3. 傘のないラインに留まり、累計3秒で失敗することと、再挑戦でリセットされることを確認する。
4. Escape/休憩・別タブへの移動で時計が止まることを確認する。
5. 帰宅後に改良版BEST、再読込後に練習済み/音設定が残ることを確認する。旧雨宿りBESTと改良版BESTは別の記録で、得点を合算/移行しない。

結果は端末/OS/browser、操作方法、気になった時刻・操作・画面とともに記録する。面白さ・傘への入りやすさ・スマホでの人物判別・音量については自動検査のPASSから推定しない。
