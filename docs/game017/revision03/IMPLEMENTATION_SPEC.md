## 今回の改良

元の雨宿りリレーrules2（左右移動・屋根・雨量・濡れ回復）から、依頼された3ライン/通行人の傘/属性得点/累計3秒/90秒帰宅のルールへ改良する候補。前工程で038と誤って作成したモデル・ImageGen素材・UIを、同じ雨ゲームのrevision03へ移管する。モデルと描画style、生成された画像の内容は流用し、不要な再生成やゲーム性変更をしない。

- 自動前進90秒/180m、上中下3ライン、PC上下/W/S、3ボタン/路面tap/上下swipe。
- 直接雨に濡れた**累計3秒**で失敗。傘で乾かない。同ライン・足元x半径0.62mが保護範囲。濡れ限界とゴールが同時なら失敗。
- 同じ人への初入場だけ属性得点。+150/−120等。重なりは最近接/同距離IDで選ぶ。案内傘の連鎖は必ず完走可能、他の通行人も往来する。
- 9秒練習は別ラインの新しい傘で1回以上保護されて成功。放置完了/再入場加点は禁止。練習はBEST/本番scoreを変更しない。
- タイトル/説明/実練習/本番/休憩/結果/リトライ。blur/hidden/休憩で時計停止、repeat/持越し入力を無視。拒否された保存はメモリfallback。
- 閉じた傘を持つ主役は無敵ではない。Image Aは既存017背景、人物側を背景へ合わせる。人物9種/家/小物の透過14asset、追加ImageGen呼出し0。
