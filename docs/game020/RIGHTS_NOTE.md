公開前のWeb名称検索で「すっきり牌合わせ」の完全一致する既存ゲーム名は確認されなかった。「PAIR TILE」は一般的語の組み合わせで、Tile Pair／Connect: Pair Tile Match等の近い名称は見つかるため、日本語を含む正式名を使い、既存固有ブランド名を避ける。網羅的な商標調査・登録確認ではない。
