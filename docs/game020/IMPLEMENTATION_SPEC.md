## 核と操作

重なった牌の中から「上が空き、左右どちらかの側が空いた」同じ柄2枚を選び、全て除去する古典ルール。PCクリック、Tab／矢印による自由牌の選択、Enter／Space、スマホタップ。誤選択・不一致・塞がれた牌の入力に罰なし。時計・期限・命・即Game Over・強制裏モードはない。

24枚（2層・6柄）／48枚（3層・12柄）の2段階。4列にして手機の牌サイズを優先する。1柄4枚があるため同柄でもどの2枚を取るかに選択がある。1盤面時間はプレイヤー依存で、30秒などの目標／制限は設定しない。

Core Loop：自由牌を見つける → 同柄の組を選ぶ → 重なり／側面が開く → 次の組を読む → 全消去。Skillは図形と中の模様の照合、重なりの判断、後の牌を開ける順序。失敗は残牌の詰まりで、同一RUNの戻す／並べ替えで続行できる。再挑戦理由は片付く感触と違う柄配置。ヒントに罰や記録倍率はない。

## 生成と救済

座標は独自の4列多層配置。ランダム自由ペア取りを上限32回試し、できない場合は各行の左右端を取る保証手順へ戻る。合法に全て剥がせる順序へ同柄を割り当て、開始時の解法witnessを持つ。ランダム生成だけを解ける根拠にしない。

ヒントは保持解法を検証し、必要なら上限付き探索を使う。探索の未証明を「絶対解けない」と断定しない。戻すは直前のペアと柄／位置を復元。並べ替えは残牌の柄数・IDを保ち、解法を検証する。残牌の形状に解法がない場合は4列の平面復旧配置へ並べることを説明し、戻す履歴をリセット。やり直しは元の盤面、次は新盤面。途中からの切替は確認ダイアログを出す。
