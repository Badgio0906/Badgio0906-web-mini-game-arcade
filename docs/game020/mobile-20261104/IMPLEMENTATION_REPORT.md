# Game020 ミニ盤面・タイムアタック・コンボ改修

2026-11-04 JST。ユーザーの「任意のタイムアタック・約12牌のミニ盤面・連続消し得点と演出」を実装。

初期選択に12牌のミニ盤面を追加。3行×4列、従来と同じ自由牌判定、必ず全消し可能な生成経路を持つ。24牌・48牌の通常盤面と無制限モードを残す。タイムアタックはチェック式で任意、ミニ60秒／他180秒。休憩・説明・確認中は有効プレイ時間を止め、期限到達時はタイムアップ結果に移る。

最初のペア100点、4秒以内に次を消すと2倍、3倍…最大8倍。得点とコンボを常時表示し、消した際に盤面を短く明るくする。`prefers-reduced-motion`時は動かさない。ヒント・戻す・並べ替えでコンボを切る。各牌IDは1盤面に一度だけ得点対象とし、戻す／並べ替えによる得点稼ぎを防止。モード・サイズ別の端末BESTは `comboV1Best:{size}:{attack|relaxed}` に保存し、既存bestPairsと混ぜない。ミニのペア数は旧bestPairsを更新しない。ミニ／タイムアタックのクリア数は別キー `mobileV1Clears:{size}:{mode}` に保存し、既存の通常24/48枚のclearedBoardsも更新しない。盤面サイズ・タイムアタック選択は再読込で保持。練習は得点/BESTを更新しない。旧24/48盤面の生成・保存・無料設定・広告・解析同意は維持。

検証：`npm run check` 成功。Game020 model/challengeの16 tests成功（従来200seedの生成とミニ100seedの全消し経路、コンボ・期限定数・undo得点稼ぎ防止を含む）。Game023と合わせた対象46 tests成功。3幅（320×720 / 390×844 / 1280×900）の通常クリックで12牌完走、6コンボ2100点、pageerror0。時計を90秒進めても休憩中は変化せず、再開後60秒でタイムアップを確認。実画面はQAのPNG、ブラウザ詳細は [Game023共通の検証記録](../../game023/mobile-20261104/QA/browser.json)。スマホ実機・人間の面白さ・実聴感は未実施。独立レビュー・統合ビルド・本番公開は統合担当が記録する。
