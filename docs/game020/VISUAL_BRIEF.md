# Visual Brief

人物・動物・キャラクターは不要。盤面そのものが主役。淡いミントの卓面と象牙色の牌、控えめな影で触れる牌を見せる。牌の輪郭と中央模様で識別し、色の違いだけには頼らない。自由牌は明るさ＋下端の点、塞がれた牌は落ち着いた灰緑、選択は金色の太枠、ヒントは青い点線で区別。

24／48枚とも4列を保ち、スマホの牌は最低52CSSpx。操作ボタン46CSSpx以上。48枚の短い画面は自然な縦スクロールを許し、画面へ縮めて判読不能にしない。選択／除去時の派手な点滅、広告演出、人物背景、急がせる時計は追加しない。サムネイルは実盤面から比例cropする。

素材採用は `icons.ts` の独自コード描画。ImageGen呼出0。実画面の採否・数値評価は独立 `VISUAL_REVIEW.md` へ分離し、この方針だけで点数を付けない。
