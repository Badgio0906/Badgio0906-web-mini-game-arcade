## 狙いと実際のモデル

体を左右へ補正しながら歩き、液体の慣性を見て押す/離す時刻を調整する。自由な横移動ゲームではなく、手の傾きと遅れる液面が中心。Game002の3車線やGame003の単発落下と別のSkill Axisにする。

体の加速度は `2.4*input + .65*lean - 2.8*velocity + gait + eventForce`。弱い不安定成分があるため、何もしないと徐々に傾く。角度の上限は±0.95rad、角速度は±1.4rad/s。杯への慣性は実際の角速度変化から加速度を計算して使う。右へ補正すると液体の加速度は左向きになる。

杯ごとの角度qは `q'' = -ω²*q - 2*ζ*ω*q' - gain*bodyAcceleration + eventShock + gaitPhase`。あなたの分はω4.2rad/s、ζ.52、gain.7。部長の分はω3.4、ζ.28、gain1。会長の分はω5.3、ζ.12、gain1.15。自然角周波数・減衰・慣性応答・歩行位相を変え、残量の倍率だけで難しくしない。制御入力は共通だが、波が重なる時刻は各杯で異なる。

初稿の固定方向条件を60Hzの公開入力で試した例：無操作は10.03秒に初めてこぼれ、31.59秒/326mで自分の杯が空になる。小さなPD補正のオラクルは1杯で180秒/2066mに到達し100%を残す。同じ補正で2回の追加を受けると180秒の残量は100/97.64/94.63%、独立した波で後の杯ほどこぼれた。大きな左右の押しっぱなし切替は0.58秒からこぼれ、180秒で自分の杯8.2%。これらはモデル比較であり、人間の自然失敗時間・楽しさ・三杯の難易度が実証されたという意味ではない。

## 徐々にこぼれる判定

内側の断面は124×82。描画とモデルが同じ値を使う。残量pに対する平均液面高さは初期量の80%で、相対傾きは液体角度−杯の角度。縁の高さ `0.8*p + tan(abs(relativeTilt))*62/82` が1を越えた分だけこぼれる。左右対称で、最大25%/秒。残量を一度に消したり、身体角度だけで終了させない。

％は杯ごと。最初に残量0になった杯で終了し、そのID/名前を結果へ記録する。他の杯の残量を0に書き換えない。音/イベントは失った量5%ごとの節目だけで発火し、液体の毎ステップから大量のSE/Telemetryを出さない。少しの飛沫は実際のこぼれる縁から描く。

## 予告・距離・選択

人とすれ違う、段差、急停止、ドア、電車の5種類が設計済みの順で巡る。方向だけはseed注入可能なRNGで選ぶ。発生1.4秒前から名前・方向・残り時間を表示する。体/液体への力は連続したSINの包絡で加え、いきなり角度や残量を飛ばさない。最初の発生は9秒、間隔7秒→5.5秒→4.8秒、最長イベント2.4秒で重ならない。前もって生成する配列は最大5件で、古いイベントを捨てる。

実ブラウザ開始前のMain追加レビューで、電車の交互揺れだけ予告方向を力へ適用していない問題を検出した。体と液体の両方の電車力へ方向の符号を適用し、最初の揺れが予告と一致するよう修正した。左右同seedの公開進行を比較する独立QAを追加し、最終8/8件成功。修正済みモデルを独立レビュー用の固定候補へコピーして再凍結した。先の固定方向オラクル値は初稿比較であり、この修正後の人間プレイ時間ではない。

距離は10〜12m/sで進み、時計は実際のモデル経過秒。500mは約47.7秒、1000mは約91秒。500mで「部長の分」、2杯を受けたRUNのみ1000mで「会長の分」。断れば現在杯数を維持し、後から受け直す操作はない。3杯から2杯へ戻せない。

選択中は距離・時刻・体・液体・予告・入力を停止する。入力は中立にするが、残量や液体角速度を回復・書き換えない。既存のイベントもその状態で停止して表示する。受諾で本当に新しい杯を追加し、別の振動状態を持つ。倍率は1杯1倍/2杯1.5倍/3杯2倍、今後の距離加点だけ。500mまで500点、2杯で1000mに1250点、その後3杯で1500mは2250点。過去の得点を掛け直さない。

## 入力と描画

Native Canvas＋DOMを採用、Phaser依存を追加しない。Gameplay EngineerがCoffeeRun/Board/contracts/称号/metadata、UI Engineerがmain/style/HTML。Mainは方針・統合・追加レビュー。QA/Feel/Visualは独立担当。

Canvas論理600×450、実1200×900。Art Directorが実際に確認したImageGenの朝の街路1枚67,398bytesを3:2のまま描く。路面の流れ、予告対象、手・袖・厚い杯の縁、clipした液面、実際のこぼれる縁はコード。杯を不透明画像で置き換えない。3杯時もx108/300/492へ置き、実液体窓を独立して大きく描く。最小画面のタイトル/選択/結果はCSSで場面全体をletterbox表示する。ゲーム中の液体窓を切り取らない。

杯は体の角度で回転し、液面は相対角度で傾くため、世界座標の液面角度がモデルのqと一致する。別の演出ループで液体を動かさない。Reduced Motionでも液体の必要な動きは残し、背景ずれと飛沫だけ減らす。各杯の％は独立したDOMメーターとして示す。

BoardがArrow/A/Dの保持、primary touch/mouseの左右保持、短いタップ、ネイティブ左右ボタンを所有する。mainはナビゲーション・Escape・開始/選択だけ。短いタップ/補助技術のclickは0.18秒の小さな補正。pointercaptureとwindow up/cancel/lostcapture、blur、visibilityで保持を解除する。ポーズ・選択・タイトル・再試行でも解除し、古いkeydown repeatが次の状態で入力しない。選択後350msの短い保護もある。相反する左右キーを同時に押すと中立になる。
