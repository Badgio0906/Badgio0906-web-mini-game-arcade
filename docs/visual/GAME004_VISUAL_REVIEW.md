Before／After の実画面を画像ツールで確認。After は Chromium の Desktop **1440×900**、Mobile portrait **390×844**。タイトル、WATCH 点灯／消灯、RECALL、終了と正解再生を取得した。ネイティブボタンの通常クリック／タッチで **LEVEL 6 / 20正解**まで進み、通常の誤入力で終了。Desktop **26.85ゲーム秒**、Mobile **26.93ゲーム秒**。

## Before / After と残る点

Before は平坦な紺の背景と九つの丸角 UI パネル。After は外側の筐体・ねじ・キーの段差、骨色と琥珀色、機器の印字、紙の記録という材料の関係がある。点灯を優先しながら、装置を操作する表現へ改善した。

必須の修正所見なし。背景の作業空間は材料の反復が中心で、今後さらに具体的な置かれ方を示せる余地はある。美術のために点灯の間隔へ残光を加えたり、ボタン位置や記憶列を変更する必要はない。実機 FPS、画面の明るさ、人間の美的好みは未測定。正確な hit area、pause 位置、七サイズ・44px・点灯時間等の不変性は別担当 QA の検証範囲で、画面採点だけで証明しない。
