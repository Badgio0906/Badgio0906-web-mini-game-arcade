## 採用仕様

- Core loop: 傾きを見る→同じ方向へ手を加速→入力を離して制動→再び立てる。倒れるまでの実プレイ秒数を0.1秒表示。失敗角約53度、すぐ再挑戦。ランキング・保存なし。
- ←→ / A・Dと画面下の左右ボタンを同じ -1/0/+1 入力へ変換。ドラッグ絶対座標の瞬間移動は使わない。両方向は中立。指が棒や接触点を隠さない。touch-action:noneとpointer capture、cancel、blur時に解除。
- 初期角±0.036radと角速度±0.008rad/sで、完全静止を避ける。リトライごとに初期方向を交代。風・障害物・アイテムはない。
- 長さ3→2.5→2→1.55→1.15m相当。12/24/36/48秒で切り替え、2秒前予告、2.4秒のsmoothstepで伸縮する。各値はmodel.tsのCONFIGへ集約。
- 120Hz固定刻み、均質棒の近似 `α=3/(2L)·(g sinθ−a cosθ)−dω`。手の実加速度（離した時の制動も含む）を使用。収縮による角運動量の衝撃はゲーム上意図的に省略し、角度/角速度を連続保持する準静的伸縮。短いほど重力・入力双方に敏感。実物の厳密な伸縮質量分布モデルではない。
- 非表示、blur、リサイズで明示ポーズ。復帰後は「つづける」で再開。長いフレームのcatch-upを制限し、復帰即死を避ける。
- 左右端の物理壁なし。手を追う表示と床の移動で、カメラ内へ収める。倒れ始めた棒を立て直す余地を画面端で奪わない。
- 目標プレイ時間は10〜60秒という仮説。現状、人間の楽しさ・適正反応時間・長押しから離す学習難度は未評価。

## Visual Brief / 素材出典

温かい生成り背景、深緑の線、青緑の袖、黄銅・コーラルの伸縮棒。抽象ゲージではなく、傾き・手首・床の移動から操作を読む。上向きに開いた掌、4本の重なる指、手前の親指、袖口と前腕、棒下端の接触影をオリジナルSVGパスで制作。棒は太い下段から細い上段へ入る5つの筒、ハイライトと継ぎ目で長さを読む。危険時だけ短い線、復帰成功時だけ小さな光と短音。

絵・CSS・発振器による音はこの試作でコードから新規制作。外部画像、写真、キャラクター、参照画像、外部音源なし。ImageGen利用0回（生成原本・promptなし）。フォントはOS搭載の日本語フォントfallback、再配布なし。第三者素材のライセンス追加なし。権利の独占性・法的権原を保証する意味ではない。配信する絵はmain.ts内SVGで、編集可能な原本も同一。採用箇所は手・棒・背景・接触影の全て。画像のサムネイル登録なし。
