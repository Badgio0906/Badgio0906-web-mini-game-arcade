# 本人試遊待ち

自動制御の生存、スクリーンショット評価は「面白い」の証明ではない。全項目未実施。

1. PCで最初の3回。説明なしでも「倒れるほうへ」がわかるか。押して離すことで回復できた感覚があるか。
2. 長い段階で12秒へ届く難度か。早すぎる失敗なら初期角、gravity、damping、速度/制動の順に一つずつ調整。
3. 12/24/36/48秒の短縮予告が読めるか。短縮中の失敗を理不尽に感じないか。
4. 実機スマホの左右親指、長押し、離す、ブラウザUI伸縮、タブ復帰。指の被り、スクロール、画面端での不安がないか。
5. 手が棒を支えて見えるか。上段が下段へ収納される絵が自然か。最短段階でも棒の動きが読めるか。
6. 音ONの立て直し音が小さく気持ちよいか。何度もやりたくなるか。
