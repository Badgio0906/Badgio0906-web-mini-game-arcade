# 本番公開保留

モデル上は17.59秒の成功列があるが、通常ブラウザのIPC/入力/フレーム量子化を含む追試2回では第2フック後に失敗した。原因をゲームの到達不能・人間の不合格と断定しない。入力clockの整合修正後も固定列の成功を確認できていないため、同一原因の修正・試験を無制限に繰り返さず保留。

元model、調整コース、起動UI、ImageGen→Pixelizer素材、39unit、4幅smoke、両失敗の入力tick/スクリーンショットは保全。mainのpublic routeからは除外。次回は作者試遊と、見える取得範囲/入力許容幅を基に設計を検討する。モデル時刻setterや判定捏造でPASSへ変更しない。
