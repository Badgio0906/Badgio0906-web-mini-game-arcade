# 落下キング 改訂03 — 刻むか、欲張るか

2026-10-05 日本時間。今回の統合実装指示書の第1節を対象とする。改訂02の王様、深度BESTキー、ジャンプなし、加速・慣性・逆方向ブレーキ、自動縦スクロールを保持する。

## 遊びとリスク

短い安全な着地を刻むか、DOWNを押し続けて普通の床を飛ばし、深い「やわらかい床」へ一気に進む。普通／移動床はホールド中に通過し、落下距離と速度をリセットしない。やわらかい床／崩れる床は実際に着地して衝撃判定し、0.18／0.12秒以上の短い停止後にホールド降下を再開する。強い着地では既存0.32秒の硬直を優先する。ホールドを離すと次の普通の床で止まる。

普通の床は6mまで安全、6〜9m未満は硬直、9m以上で着地失敗。やわらかい床は9mまで安全、9〜12m未満は硬直、12m以上で着地失敗。実際に止まった床だけが次の落下距離をリセットする。途中のトゲ・壁針はホールド中も有効。無限コースで受け止める床を逃し12mを超えた場合も落下距離オーバーで終了する。死亡理由は結果に明記する。

DEPTHは最深到達m、NICE DROPは生存限界の85%以上の深い着地。深いルートは移動を速め、NICEを獲得する代わりに、着地硬直と次の進路判断を伴う。旧BEST保存キー／得点単位は移行しない。

## 床の生成

6つのパターンをランダムにつなぐ。4段の安全な足場間隔を2.1〜5.8mへ変え、幅72〜112pxの普通・狭い・広い足場を混在。段差の短い箇所は実際の飛行時間に合わせて横移動量を制限し、全段に全身で着地できる経路を残す。

各パターンの3段目はやわらかい床。パターン先頭から10.6〜10.8mの深い受け止め地点になり、最初の2段をホールドで飛ばす選択ができる。前半の危険床は、安全な着地湾と斜めの深い降下通路を確保する。4段目は左右いずれかの細い石床で、中央も含むトゲが次の判断を要求する。中央を維持する単調なルートは成立しない。

30m以後の一部パターンに着地後1.25秒で崩れる足場、100m以後の一部に小さく左右移動する足場を混ぜる。床種を主役に増やさず、距離差・通過・衝撃・追走を中心にする。危険な別足場は最後のトゲ付き段に置く。

スクロールは18px/秒から毎秒0.22px/秒ずつ最大36まで。最初のDROP猶予約2.85秒を保持する。安全な床で考えすぎると上端に置いていかれる。

## 入力・表示・素材

PCの↓／S／Space、DROPボタンのマウス・タッチは押下から離すまでホールド。左右とDROPを同時に押せる。keyup／pointerup／cancel／lostcapture／blur／pause／retry／titleで保持状態を解放する。ボタン上に「押し続けて連続降下」、HUDにHOLD DROP!、やわらかい床にSOFT CATCHを表示する。

王冠・白ひげ・紫衣装・赤マントの既存24×36ドット絵を継続採用。やわらかい床を既存パレットの明るい青緑のクッションへ変更し、背景・王様・普通の石床から読み分ける。Image Generationは追加呼出しなし。サムネイルは今回の実入力落下画面から統合担当が更新する。

## 独立練習

6段階：DROP→中央トゲを避け右→中央トゲを避け左→DROPを押し続け2枚の床を通過してやわらかい床へ→10m落下の石床衝撃をゴーストで実演→停止ゴーストが追走天井に置いていかれる実演。ホールド練習はタップ連打や待機で達成できない。途中の床に止まれば同じ段を安全に再試行する。得点・BEST・CREDIT・本番runイベントと分離する。

## 受入と限界

対象単体テストは距離境界、64seed安全経路、5000m継続、可変間隔、深いホールド着地、衝撃の非リセット、ホールド中のトゲ死亡、6段練習を検証する。ブラウザはPC／390／320／横画面で通常キー・マウス・タッチ入力を行い、readonly診断で進行を確認する。独立Feel／Visual／QAと統合build・productionは統合担当が記録する。人間の面白さ・実機の親指操作・音・FPSは未実施として残す。
