# 落下キング 人間プレイテスト

自動検証とは別に、実際のPCとスマートフォンで確認してください。面白さの最終評価・実機の快適さは人間によるプレイ後に記録します。

- 初回の説明と4段階の練習だけで、DROP・空中の左右移動・落下距離が理解できたか。
- 最初の10秒で、次の足場へ降りることが気持ちよかったか。
- 左右を離したときの慣性と、反対方向でのブレーキは学べたか。
- 次の2〜3段が見え、落下先を自分で選べたか。
- SAFE / HARD / SPLATの理由と距離表示は納得できたか。
- 短い安全ルートと、段飛ばしで進むリスクを選びたくなったか。
- ソフト・崩れる・動く足場を見た目だけで区別できたか。
- 1000m以降も先を見たくなったか。難しさが理不尽にならなかったか。
- BEST更新を目指して、もう一回遊びたくなったか。
- スマートフォンで左右とDROPを押し分けられ、長押し解除や画面移動で入力が残らないか。
- 小さな画面でもDEPTH・FALL・キャラクターを読めるか。
- 音量・ミュート・ポーズ・一覧へ戻る操作が自然か。

記録：端末／ブラウザ／初回到達深度／最高深度／面白さ1〜5／操作感1〜5／死亡の納得感1〜5／再挑戦したい理由／改善点。
