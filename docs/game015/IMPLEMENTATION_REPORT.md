# Game015 落下キング 初版の実装・検証報告

最新のキャラ拡大・トゲ／壁の針／鳥の改修は [改訂01](revision-01/IMPLEMENTATION_REPORT.md) を参照。以下は初版の検証記録。

15本目として実装済み。独立レビューと最終QAは合格。人間による面白さの最終判定は未実施で、無制限プレイの試作版として扱う。

## 実装

DROPで現在の足場を抜け、重力で降りる。空中では左右の加速・慣性・逆入力によるブレーキを使う。ジャンプはない。連続落下距離と着地素材からSAFE/HARD/SPLATを判定し、深度を主得点、NICE DROPを別回数として表示する。BESTは端末内に保存する。

通常・柔らかい・崩れる・動く足場を、物理的な到達可能性を確認したパターンから生成する。深度で地形と4種類の背景が変わり、1000m到達後も続けられる。保持する足場は有限。四段階の実操作練習ではDROP、空中操作、安全着地、危険な衝撃の順に学び、練習の結果を本番のBESTに保存しない。

256×448の整数ピクセル描画、16×16タイル、16×24の王様、22枚の動作フレームを用意した。高解像度画像を縮小した疑似ドット絵は使っていない。中央は暗く静かな空間、詳細タイルは側壁に配置して足場を見分けやすくした。専用8-bit音声はミュートとポーズに対応する。サムネイルは実際の落下中キャンバスを切り抜き、補間せず配置したもの。

ポータルに日本語・英語タイトル、紹介文、実画面サムネイルと個別ページを追加した。既存14作品のゲーム固有ソースと移行済み出力127ファイルは公開済み14本版と完全一致している。共通練習の拡張、ローカル日本語フォント、イベント定義以外に既存ゲームの仕様を変更していない。

## 独立レビュー

[Game Feel](GAME_FEEL_REVIEW.md)はPASS。実入力でPCの1000m到達・継続・自然な失敗とリトライ、スマートフォン相当の同時タッチと慣性操作を確認した。PCの1000mは266.494ゲーム秒であり、企画上の想定時間と実測を混同しない。5000mの確認は独立モデルシミュレーションで、ブラウザプレイではない。

[Visual](VISUAL_REVIEW.md)は初回83点、FALL数値拡大後の限定再確認で84点。小画面の練習・本番で数値、王様、足場、操作ボタンの重なりがないことを確認した。

練習ターゲットの初期到達不能、ヘッダーボタン操作後の最初の方向入力、背景中央の過密装飾、未指定faviconによる404を見つけて修正した。初回の失敗記録は削除せずQA資料に残している。
