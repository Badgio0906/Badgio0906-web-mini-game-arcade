# 落下キング 改訂01

実装・独立Game Feel・最終QA合格。初版の公開結果と区別して記録する。

## 変更

キャラは16×24から24×36へ、当たり判定は12×22から18×33へ拡大する。足元を基準に配置し、練習の落下距離は変えず開始位置・目標位置だけを12px下へずらす。壁際でも24px幅が画面をはみ出さないようにする。

全幅の安全床を廃止し、早期にトゲ床と狭い安全な着地場所を導入する。トゲ床は約7.6mで登場する。壁の針は常に見える発射口を持ち、接近すると0.9秒警告してから突出し、0.65秒後に引っ込む。約16mから登場する鳥は左右に揺れ、安全な着地先だけでなく降りる時刻も選ぶ必要を作る。鳥の高さは上下の足場で待つ王様に重ならないよう、身体の高さと隙間から計算する。

当初の落下衝撃の閾値、左右操作・DROP、ポーズ、端末内BEST、無制限の試作プレイを維持する。既存14本のゲーム固有ソース／旧作品出力127ファイルは初版公開コミットと同じ。

## 検証

単体20ファイル181件、TypeScript検査、Viteビルドは成功。015専用JSは51.18kB（gzip16.79kB）、ローカルフォントは158248 bytes／1011文字。旧8装飾記号のフォールバックを除き、日本語はローカルフォントで配信する。[モデルの調整・18件の検証](../REVISION_GAMEPLAY.md)、[整数ピクセルの検証](PIXEL_ART_AUDIT.json)、[レビュー候補のソース](REVIEW_CANDIDATE.json)を保存した。独立Game FeelはPC・390pxスマートフォン相当の実操作で合格。中央DROPの自然なトゲ死亡15.1m、壁の警告と約4mでの針接触、鳥を約2.6〜2.9秒待った後の20m安全着地、別タイミングの16.46m鳥接触を確認した。[実操作レビュー](GAME_FEEL_REVIEW.md)。

初回QAで320px画面の長押し終了が結果画面のタイトルクリックへ変換される不具合を発見し、実際のpointerdown/up/click記録で特定した。入力を開始した画面と現在の画面を照合し、画面遷移をまたいだ古いクリックを受け付けない修正を入れた。修正後の実操作8ケースは成功し、新しいタップ、Enter、タイトル操作を確認した。5種類の画面サイズで練習・トゲの安全着地／実接触・ポーズ・自然な結果・リトライを確認。鳥の長い失敗説明も、実際に獲得した結果を320×568・844×390へ回転／縮小して44px操作とクリッピングを確認した。ルート／サブパスの1440×900・390×844、公開用ビルド4ケースも成功。初回の失敗と修正前のソース記録は保持する。

[最終QA記録](QA_REPORT.md)、[8ケースの実入力](QA_REPORT.json)、[4ケースの公開用ビルド](PRODUCTION_SMOKE.json)に記録する。最終ソースは [SOURCE_FREEZE.json](SOURCE_FREEZE.json)、集約SHA-256 `11c3032d3804a960690abbf19cbb94ddca5a531ed82fa98cccd13ae74aea71f2`。独立Feel後の変更は実画面サムネイルと結果操作の持ち越し対策だけで、モデル・描画・フォントは同じ。共有26経路（ポータル＋001〜011＋015、ルート／サブパス）の配信も全件成功。[配信記録](PRODUCTION_ROOT_SUBPATH_AUDIT.json)。015の実際の初回JS合計は81366 bytes、画像0 bytes、フォント158248 bytes。専用JSに加え共通chunkを含む。公開先確認は次工程。人間の面白さ・実機タッチ・音の体感は別途評価する。

## 人間に確認してほしい点

大きいキャラでもトゲの隙間に狙って着地できるか。壁の針の予兆を認識でき、反応する時間があるか。鳥を待って避ける操作が理解できるか。中央で降り続ける初版より判断が増え、リトライしたくなる難易度になっているか。
