# 落下キング 改訂02 — 縦スクロール追走

2026-10-05 日本時間。今回ユーザーが依頼した中央安全路の解消、下降追走、参考画像方向の王様、タイトル・サムネイル・練習を反映する。018候補を保持し同時公開する。

## 遊び

左右の加速・慣性・逆方向ブレーキで次の足場を選び、DROPで現在の足場を通り抜ける。ジャンプなし。停止しても下降カメラが進み、画面上端へ置いていかれると終了。スクロール18px/秒から毎秒0.22px/秒ずつ最大36へ。序盤最初のDROP猶予は約2.85秒、進んだあとはカメラ中央付近に追従して判断時間を確保。従来の6m安全、9m危険（柔らかい床は9/12m）・深度BEST保存を保持。旧BESTキーは同じ。

6種の左右中央パターンをランダムにつなぎ、幅80〜112px・左右移動最大66px・落差4.4〜4.6mの安全な着地経路を各段で生成。中央にもトゲと危険な足場。安全な経路に飛び続ければ必ず到達できる余白を保持し、中央固定では死亡する。安全路に待ち時間の読めない鳥を生成しない。壁針は予兆を保持。

## Visual Brief / 素材

ユーザー添付の画像は方向性参照。24×36のオリジナルnativeドット絵を座標で手描きし、黒輪郭、三つ山の金冠と赤宝石、白ひげ、紫衣装、赤マント、金のベルトと靴を小さく読み分ける。待機・DROP開始・落下・左右・着地・強い着地・死亡の8状態、各2フレーム。死亡では王冠が飛ぶ。ImageGen呼出し0回。制作スクリプトtools/author_fall_king.py、採用src/games/game015/kingPixels.ts、一覧assets/game015/revision-02/king-animation-preview.png。参考画像そのものを配信へ貼らない。

タイトルに同じ王様の拡大ドット絵、プレイ画面・練習にも同一スプライト。サムネイルはnative実入力の落下画面を同比率で縮小し左右letterboxのみ、合成しない。
