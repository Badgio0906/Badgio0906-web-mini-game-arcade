# Game003 改訂：芸術的な釣り合い

対象はGame003のモデル・Phaser表示・固有練習・保存・計測。共有SDK、他作品、Catalog、フォント、サムネイルは統合担当が所有する。

現行は既にフル幅の張り出しと全支持面の上部重心検査を持つ。切落し方式ではない。今回追加する核は「十分な張り出し→反対側へ置く→実際の支持余裕回復→確定した組の芸術点」。同じ寸法に説明のないランダム重量を与える現行を、幅×高さに比例する同一密度へ修正する。

Space / Enter / Click / Tapで揺れる建物を落とす基本入力とPERFECT許容6px、落下・settle、15mの一度だけの選択は維持する。C国は揺れ速度2倍・PERFECT追加点3倍。芸術点へはPに一度だけモード倍率を反映する。

各接触面の重なり区間・上部合成重心・余裕を保持し、最も危険な支持面と基礎全体重心を別に表示する。空中固定、視覚だけの張り出し、入力左右順だけの採点、待機中の加点、ランダム崩壊は禁止。

直近2配置の横ずれが十分・逆方向・全支持成立・先の弱い支持面または基礎偏りが改善したときだけ組を成立させる。受賞した建物IDは次の組へ再使用しない。中央PERFECTと芸術点を別集計。旧保存 `best` / `bestBonus` は保持し、新規則のfloor/bonus記録を `rules2:*` へ分離する。

練習は別TowerRunで中央→張り出し→反対へ戻す3着地を行う。失敗は安全に練習をやり直す。本番RUN、BEST、CREDITへ混ぜない。説明・練習は初回から任意。

最終値と調整理由、通常入力での実画面確認、残課題は実装報告へ記録する。自動入力の技術成立と人間の面白さ・実機評価は別。
