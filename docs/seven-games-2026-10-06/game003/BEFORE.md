# 改修前の観測

基準HEAD `5b2dff83fe9196de82eaa7d8b0f15b35d7ff4a34`。Mainが通常開始入力で撮影した [PC](../QA/before/003-desktop-play.png) / [phone](../QA/before/003-phone-play.png) を実viewした。建物ファサード、街、クレーンの識別性は既に成立しており、PCの570×684付近の大きな領域は維持する。

コード照合では建物の張り出しは既に切り落とされず、`evaluateTowerStability` が全支持面より上の合成重心を逆走査している。一方、芸術ペアは存在せず、画面の主フィードバックもPERFECTと単一BALANCEのみ。全体重心と危険な継ぎ目は別表示されていない。既存の練習は共有の1回DROP toyで、釣り合い回復を体験しない。

幅・高さが同じ建物にも55〜75kgのランダム質量を与えるため、見た目から同寸法の重さを判断できない。新しい芸術積みでは同一密度に統一する。旧 `best` は階数、旧 `bestBonus` はPERFECT専用点。改訂後の芸術点を旧BESTへ黙って混ぜない。

人間によるプレイ評価や全フレームの既存アニメーション審査は、このbefore撮影だけでは確認していない。
