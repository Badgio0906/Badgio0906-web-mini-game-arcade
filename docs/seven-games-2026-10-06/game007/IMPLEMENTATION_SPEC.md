# Game007 改訂02 — 行き先と輸送時間

最新依頼は [REQUEST](../REQUEST.txt) 6章。タイトル・ID・URL・既存素材・ミュート保存を維持し、重量超過即終了／無限上昇／積載移動点／20F高速モードは今回の新ルールへ置換する。

通常便は1F→10Fの上昇のみ。候補は各階2〜3組、乗車・見送り・候補を残して出発を選ぶ。乗せた時点では0点、目的階の降車で依頼点だけ加点。容量450kg、超過する乗車は無効。人物を体格評価の対象にしない。

画面は現在階・次停止階・現在/上限重量・候補追加後重量・行先・配達点・期限・残時間・乗車名簿・次2階の確定候補を表示。時間は実際の判断時間と一貫した操作費用（乗車0.7秒、見送り0.2秒、出発扉0.4秒、1階移動1.0秒、降車のある階1停車につき0.8秒）。各階で次の候補を確認する。降車がある時だけ追加0.8秒の停車を1回払うため、同じ目的階にまとめると降車停車を減らせる。期限はRUN内経過秒、最短配達見込みは現在の乗車・移動・既存降車停車をコードで計算する。

3つの手作りシナリオをRUN毎に順送り。遠い重い低効率荷物と次階速達、同階団体と分散降車、重くても高得点配送を混在。政策比較は通常モデルのコード計算で証拠化し、Jevに数値計算は任せない。十分な通常点でだけ屋上特別便を選択可能。終了して確定か、容量を大きく占める引越し荷物と途中速達の追加便を選べる。

記録はrulesVersion=2、BESTはbest:transport:v2。旧bestを削除・加算しない。端末内400イベントの既存Telemetryを使い、乗車/見送り/出発空き/到着配達/期限切れをspecific_game_eventsで記録。練習は同じモデルの短い別シナリオを使い、RUN/BEST/本番telemetryへ混ぜない。初回3択、練習スキップ可。

操作は←/Aで見送り、→/Dで乗車、Spaceで出発。repeat・同phase連打・跨ぐreleaseを抑制し、ヘッダーfocusは本番入力にしない。ポーズ/非表示で時計全体停止。画面・モデル・保存不許可を検証する。人間の楽しさ、実機親指、聴取/FPSは自動QAとは別の未実施項目。
