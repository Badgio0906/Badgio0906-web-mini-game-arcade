# Visual Brief

既存の暖かい路面と車3種、寸法一致した全車体表示を維持する。新しい判断の核は枠の配置、指定の輪郭、停止後の余裕。安全／挑戦は色だけでなくSAFE／×1.4の文字と線種で区別し、選択前に双方の全体が見える。選ばない枠は薄い破線と「対象外」で区別する。重要HUDはstage内の上端に載せ、角度・強さ・ブレーキボタンは既存consoleで44px以上を保持する。

ノーブレーキ／ニアミスは成功時の補助評価。走行の曲線と車体四角を一致させ、ニアミスは接触していない車体間隔で判定する。成功時は車の停止位置を残し、精度grade・余裕px・加点が読める。背景装飾を障害物に見せない。PCでゲーム領域を縮めず、狭幅と短横画面では説明を減らし操作と指定枠を残す。

新しい画像素材は作らず既存の車WebP3種を使用。画面とサムネイルの原本は通常入力による実プレイから取得する。独立Visual点と人間評価は実装者の見た目判断から分離する。
