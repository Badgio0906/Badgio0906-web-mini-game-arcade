# Game006 rules v2 — 選ぶ・攻める・止める

対象はGame006のみ。既存の角度→パワー、定曲率円弧、42×70車体、10台後の禁断選択、旧BEST/mute、CREDIT OFFを保つ。最初3台は単一枠、その後は同じ駐車場に安全／挑戦の2枠を提示し、角度ゲージ開始前に指定する。選ばない枠は対象外と常時明示する。全枠は既知の合法円弧と車体全区間のswept接触検証で作る。

走行中の独立した新入力で1度だけブレーキ。方向・曲率は不変、有限時間の等減速度で停止し再加速しない。未使用時の速度・経路・終点は旧実装を維持する。入力の押しっぱなし、Powerの押下、別pointer/keyboard混在から持越さない。

得点は従来の精度・連続PERFECT点×禁断2×挑戦1.4。ノーブレーキは成功点の10%を別加点、ニアミスは実矩形同士の最小距離を使い、接触したRUNには加点せず1駐車最大20点。駐車成功と精度が主役。精度、停止余裕、ブレーキ、追加点を短く提示し、失敗理由は実形状／進行距離から分類する。

旧bestは読み取り表示のみで残す。新best-rules-v2へ独立保存し、HUDとResultは新ルールと明示する。端末内400イベントに枠選択／ブレーキ／精度／ニアミス／失敗理由を区間ごとに記録する。外部Jevや共通記録基盤は接続しない。

Game006独立説明・練習：角度→パワー、過大Powerからの有限制動、2枠指定を実際のParkingRunで体験。いつでもスキップ可。練習中は本番BEST・CREDIT・run_start/endを更新しない。

設計仮説：予測線に沿った空間判断に、成功率／倍率の選択と制動タイミングを加える。人間の楽しさ・親指・音・FPSは自動検証と分離して未実施とする。
