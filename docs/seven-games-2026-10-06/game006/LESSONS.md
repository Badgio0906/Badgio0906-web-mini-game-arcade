# Game006 v2 — 次の改修へ

- 2つの枠を表示するなら、先に両方の円弧・車体・共通障害物を検証する。片方を選んでから障害車を入れ替えない。
- 制動は曲率を変えず有限距離で止める。旧モデルをそのままtest-only archiveし、同じ入力の未制動結果を比較すると「操作感の追加」と「元物理の変更」を分けられる。
- ニアミス候補は走行中の実矩形間距離で集め、成功時に一度だけ精算。後の接触や枠外に点を出さない。
- 新しい入力保持guardはblurだけでなくpause/visibility境界も解放する。PowerのSpace押下、リピート、同時pointerを制動へ持ち越さない。
- タップの到着遅延を25ms固定で見込むcollectorは、正しい制動が遅れて見える。readonly gaugeから実測leadを更新し、失敗原本と実際の入力結果を保つ。
- Vite serverが分かれていてもnode_modules/.viteは共有され得る。独立snapshotはcacheDirを分ける。headlessソフトウェアWebGLの遅さを実機FPS不合格やゲーム制動の不具合に転用しない。
- 成功popupと枠ラベルを重ねない。非接続CREDITを表示しない。LOT番号は成功台数ではなく現在描いているlayoutから取る。
- 人間が挑戦1.4倍と安全を選び分ける楽しさ、制動の親指感覚は未実施。モデルと通常ブラウザ入力の成立で代用しない。
- BESTは保存／Resultだけでなく、終端フレーム後に残るstage HUDも更新する。中断RUN／単独score／durationにもrulesVersionを付け、旧新比較で終了種別に依存する欠損を作らない。
