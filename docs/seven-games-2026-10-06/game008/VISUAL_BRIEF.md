# Game008 — 手元の再設計

手元を斜め上から見下ろす、温かいカフェからオフィスへの配達。青緑の袖、生成りのカフ、手首、掌と曲がった指が木の厚いトレーの両端に一貫して接続する。白い陶器は厚い楕円縁、内部、曲面の本体、胴から独立したループ状の取っ手を持つ。コーヒーは内側にクリップし、器の回転を打ち消した重力方向＋独立した慣性角を描く。あふれる側を液面の高い端から決め、左右メーターと同一の符号を使う。

最初に neutral / left / right / spill を実CanvasのPC・phoneサイズで撮り、読める手・腕・陶器・トレーか確認してからゲーム拡張へ進む。意図的なCanvasベクター制作。Image Generationを実行していない場合は生成利用と記載しない。実体を絵として確認し、ラベルで判読性を補うだけの採用はしない。

上側は遠近の廊下と予告された段差・曲がり角・床継ぎ目。手元を隠さない薄いHUDに残距離・締切・残量とバランスをまとめる。2杯でも同じトレー、同じ左右操作。
