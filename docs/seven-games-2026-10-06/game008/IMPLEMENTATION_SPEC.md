# Game008 配達改修（rulesVersion 2）

対象は008固有コード・HTML・テスト・絵だけ。IDと英題COFFEE WALK、左右の長押し、液体の慣性、ミュート、ポーズ、保存失敗時のプレイを維持。旧 `best` は削除も書換えもせず、v2 BESTは `best-delivery-v2`。

180mの1配達、慎重4m/s、急ぐ8m/s、締切32s。初期値をモデル比較で採用した。慎重のみ45s／急ぎのみ22.5sの間の締切。固定の段差48m・左曲がり94m・床継ぎ目142mは16m前から環境絵と文字で予告する（急ぎでも2秒）。慎重に切り替えると減衰が増え、危険の慣性衝撃が小さくなる。モデル内に予告なしの危険乱数はない。

←/A：左端を持ち上げる。→/D：右端を持ち上げる。器の右が低いなら右を支え、押しすぎに注意。SPACE／中央大ボタンは速度を1回切替、repeatでは切り替えない。指とキーは独立し、左右同時は相殺。pointercancel・capturelost・blur・pause・phase切替で保持入力を解除。

液体は器と異なる独立振動系。液面の相対角 `liquidAngle - bodyLean` で高い側を決め、内側ellipseマスク・coffee形・spill流・左右メーターを同じ符号で描く。体とトレー、手・袖・陶器・取っ手は同じtransformなので前後関係が反転しない。

残量20%以上の全杯を期限内に届けた場合のみ、`floor(1000×杯数 + 10×残量合計 + 40×余裕秒)` を加算する。空カップ、締切失敗は配達点なし。1配達の後は終了または同じ操作の2カップ追加配達を選ぶ。2回目で完了、最大同時2杯。

3開始選択は任意。練習は別モデルをreset、締切無効で、左右の実傾き・急ぐから慎重への切替・最初の段差を慎重に越えることを確認する。production run_start/end・BESTへ混ぜない。練習はやり直し／離脱可能。

Telemetryは既存端末内400件のみ。pace、warning、hazard、5%区切りspill、delivery、choiceをspecific_game_eventsへ保存する。フレーム保存も外部APIも導入しない。
