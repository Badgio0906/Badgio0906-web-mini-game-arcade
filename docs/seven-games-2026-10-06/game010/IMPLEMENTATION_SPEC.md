# Game010 改訂02 — 議事録サバイバル

旧内職・監視タイミング判定は取り除く。3議題の会議で、発言カードを記録し「担当／作業／期限」を更新する。提案と雑談にも拾える単語があるため、全カードを押すと誤記・余分な記録コストになる。role色・正解iconは表示しない。明示的な言語で提案・決定・訂正を区別する。

12個の構造の異なる手作りscenarioを用意。各発言に話者、文、役割、欄への値、決定state変化、想定読解時間。条件分岐は発言中で条件の成否を明示し、条件が不明のまま採点しない。通常scenario9、追加用3。最終正解はdecision/correctionのみreduceして算出し、静的expectedと一致検証。

発言は最低3.8秒、文量に応じ最大7秒。直近2枚の履歴も記録できる。議題ごと2回「もう一度」を使うと進行を止めて同じ文を読み、再開ボタンを押すまで停止する。正解は教えない。

各正答欄100、全3欄100、正しい訂正対応30、連続完全議題20/段。雑談・提案の記録は提出時25減。2欄以上の誤記を大失敗とし2回で終了。1誤記では学んで次へ。3議題後は記録確定か追加議題を選び、追加は二重訂正・確定条件によって深める。倍速化しない。練習は提案を無視／訂正で置換／聞き返し停止の実操作を検証し、本番記録には混ぜない。

新BESTはbestRules2、旧bestはそのまま旧ルール欄へ。ゲームID／URL／邦題／英題維持。CREDIT OFF、広告・外部判定は追加しない。短いイベントを既存local telemetryへ保存。人間の読解・楽しさは独立して未実施とする。
