# Game009 改訂02 — 机の物探し

対象は009のみ。旧印鑑4属性だけの探索を、26基本種（非印鑑24）の形状探索へ変更。名前、色、キャップ等の特徴を同一predicateで判定し、同条件の全個体を正解とする。同じ机を3問使い、机の交換時に9→16→24個へ増やす。早い段階は見本を表示。

各道具は専用の手描きSVGパス、印面・刃・液晶・歯などを持つ。色差分で種類を水増ししない。SVGの描画された形が入力を受ける。紙が上にある時は紙自身が遮蔽し、折れた端を押して持ち上げる。細長い品は少し斜めに配置する。小画面は物を縮小しすぎず、机だけ縦スクロール可能。

1RUN75秒、誤答は2秒減少＋連続発見リセット。発見100＋残り検索時間bonus最大30＋散乱bonus最大15。整頓は2.5秒と散乱bonusを次の机まで失う程度の小コスト。整頓は紙を除き整列し、物を減らさない。入力はphase guardで正解後0.45秒保護。練習は物品／紙／整頓を実操作して独立終了。本番BESTはbestRules2へ保存、旧bestは保持して旧ルール欄へ表示。

初期調整値は人間試遊前の仮説。広告・CREDIT・外部送信を導入しない。端末内400件とspecific_game_eventsを使う。独立Visual/Feel/QAと実機・人間の楽しさを別結果にする。
