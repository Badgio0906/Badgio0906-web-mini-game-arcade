## 手順

1. PCと実機スマートフォンで、Preview版・端末・画面方向を記録する。初見評価にはそのゲームの練習履歴がないブラウザプロフィールを使い、他の保存データを無断で消さない。
2. ポータルからゲームを選び、タイトル→短い説明→実操作練習→成功→本番へ進む。最初は助言せず、迷った画面・操作・本人の言葉を記録する。練習の説明を読む時間と、操作開始から成功までを分けて測る。
3. 本番を自然に遊び、最初の終了理由と時間・スコアを記録する。最大3回を目安に自由に再挑戦してもらい、続けたい/止めたい理由を聞く。到達していない特殊展開を先に説明しない。
4. タイトルへ戻り、2回目のすぐ遊ぶ導線と再練習を試す。練習後に本番が初期状態で始まること、ポータルへ戻って別のゲームも選べることを確認する。

練習5〜20秒は通常の操作成功の設計目安で、遅く読んだ人を不合格にする締切ではない。補助が必要だった場合は補助前と補助後を分ける。回答を知る自動plannerの成功秒数を初見の計測に使わない。
