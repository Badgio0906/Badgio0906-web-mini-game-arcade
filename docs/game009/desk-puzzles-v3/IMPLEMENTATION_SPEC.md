# 机の小さな謎解き / Rules 3

12種類の固有問題を2～3段階で解く。事務用品のSVG26種を維持。

依頼メモを読み、紙をめくる／書類を動かす／引き出し・小箱・入れ物を開ける／メモを読む／物を選ぶ。各問題は目的・手掛かり・操作列・正解・追加ヒントを `puzzles.ts` に持つ。12種類は紙、引き出しと小箱、裏面メモと写真立て、留守電とトレー、カレンダー、ノートとしおり、金具とファイル、封筒、ペン立てと収納、書類トレー、付箋とカップ、電卓と番号箱。単なる対象名の変更ではなく操作経路が異なる。

90秒。発見200＋前提操作数×50＋速さ0～50、ヒントで当該発見−30。誤答−2秒。12問を一巡するまで同じ問題を繰り返さない。練習は紙→ペン、引き出し→小箱→印鑑の2問、時間無制限・得点0・記録除外。

保存は `web-mini-arcade:v1:game009:bestRules3`。旧 `best` と `bestRules2` は読み取り表示し上書きしない。音設定は維持。共有カタログ／recordsの版とキー切替はMain担当。
