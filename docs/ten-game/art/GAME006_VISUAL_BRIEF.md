# Game006 ギリギリ駐車 ～PARK IT!～ Visual Brief

2026-10-04 / Art Director / HYBRID・明るい都市型駐車場。

## Design Goal / Mood

小さな日本の駐車場で、車の向き・進む強さ・枠との位置関係を一目で理解できる画面を作る。淡いコンクリート、ミント色の区画、朱色の安全ポール、濃いアスファルトの輪郭。クリーム#f4ebd5、墨#31464e、ミント#73a99a、朱#d26951、黄#e9bb58を基準とする。地図の精度を保ち、青いホログラムや巨大なダッシュボードにはしない。

## Composition / UI

Desktopは中央の広い駐車場と、その下の薄い運転コンソール。左側に大きな宣伝文を置く共通テンプレートを使わない。STEP1「角度を決める」→STEP2「強さを決める」の現在段階を大きく表示し、確定済みの角度・Powerを残す。Mobileは駐車場を主役にして、段階表示と一入力の操作面を近づける。スコアと成功台数は上、CREDIT・ミュート・ポーズは小さく、操作と選択肢は44px以上。見出しは幾何学的な太めのサンセリフ、数字は読みやすい等幅。開始・結果は駐車券の表現。

## Character / Object Design

真上から見た朱色の小型車、紺のセダン、ミント色の小型バン。窓・屋根・ボディの大きい形が縮小しても分かる。全画像の内容矩形にミラーと車輪も含め、モデルの物理矩形の内側へ合わせる。画像の見かけだけを当たり判定より大きくしない。外観の違いから勝手に車速や質量を変えない。

## Background

路面、細いひび、区画線、縁石はコード。駐車可能範囲の角・回転・幅は必ず実モデルから描く。背景に描いた車を追加の障害物に見せない。軌道予測は、実装モデルが提供する場合だけ正確なコード線で表示する。

## Code / Generated / Hybrid

Generatedは車3台の透過アトラス。Codeは駐車場、正確な区画・位置・回転・計器・文字・ボタン。Hybridはモデル矩形に合わせた生成車＋コードの影・路面・タイミング表示。画像で区画や数字を決めない。

## ImageGen Plan / Asset Contract

3台を横に並べた、余白のある透過シート。全車が北向き、完全な真上の正投影。車体全体を入れ、影・路面・人・文字・ロゴなし。朱の小型車、紺のセダン、ミントのバンを同じ画風で生成する。

採用ファイルは`car-compact.webp`、`car-sedan.webp`、`car-van.webp`、各192×320程度。実際の生成セルと内容bboxを確認して切り出し、比率を保つ。目標合計90KB以下、上限140KBは実サイズでの必要性を記録。原本と索引は`assets/game006/`、配信採用分だけ`public/assets/game006/`。

実生成原本と最適化済み`car-compact.webp`をArt Directorが実際に確認し、正投影・車種差・透明余白・全車輪を承認。3台合計52,134bytes。これは素材承認であり、完成画面のVisual Gate合格ではない。

## Animation / Error Clarity

1回目で角度針、2回目でPowerが止まり、選択結果に従って車が走る。モデルと異なる方向へ見える装飾移動はしない。成功は短い駐車完了の固定とGOOD/GREAT/PERFECT PARK。失敗は接触点・枠外など実際の理由をコードで示す。狭すぎる枠の選択では、実際の枠と安全な回避を示し、受諾後の「禁断駐車」を常時小さく表示。Reduced Motionは飾りを減らしても結果・段階を変えない。

## Avoid List / Quality Gate

斜めのアイソメトリック駐車場、画像の区画、はみ出すミラー、仮の車写真、巨大計器、区画を隠す風景、段階が同時に全部強調される表示を避ける。実Desktop1920×1080とMobile390×844でタイトル・角度・Power・走行・失敗・狭い枠を確認する。独立A〜H合計80以上、F12/15以上、H12/15以上、最大3回。不合格継続はHUMAN ART REVIEW REQUIRED。人間の遊び・実機性能は未評価。
