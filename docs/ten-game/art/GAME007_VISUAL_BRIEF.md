# Game007 まだ乗れます ～ELEVATOR OVERLOAD～ Visual Brief

2026-10-04 / Art Director / HYBRID・少し古いオフィスエレベーター。

## Design Goal / Mood

普通の業務用エレベーターが、変な荷物で徐々にいっぱいになる。ワイン色の扉、真鍮の枠、クリームの表示板、灰色の床。ワイン#733d47、真鍮#b78e50、琺瑯#eee6d3、墨#343b3c、緑#617d64。Game004の実験装置とは異なる、公共の昇降機と人の荷物の世界にする。

## Composition / UI

Desktopは縦のかごと、横の乗降名簿。上の「326 /450 kg」と次の「82kg」を最大の判断情報にし、階数・人数・効率は従属させる。左右の「乗せない」「乗せる」は扉の操作盤として下に並ぶ。Mobileは現在荷重→次の対象と重量→かご→左右操作の順。44px以上の操作、太い等幅数字、少し古い社内看板のサンセリフ。丸い説明カードをかごの上へ重ねない。

## Character / Object Design

会社員、配達員、来客の3人、巨大な観葉植物、コピー機、冷蔵庫、箱4個の台車。普通の顔と普通の機械のまま、規模・組合せで笑いを出す。物体へ絵文字の顔を付けない。次に乗る対象は扉の前へ大きく、現在乗っている対象と混同しない。重量・行先は画像から推測させず、コードの数字で示す。

## Background

コードの真鍮枠・扉・壁・床・控えめな金属反射。かごの境界を明確にする。混雑時に全員を極小へ縮めず、読める数を配置して残りは名簿・人数でも示す。降りた対象と減った荷重を短い乗降表示で対応させる。

## Code / Generated / Hybrid

Generatedは人物と荷物7個の個別透過素材。Codeは扉、かご、荷重・容量・行先・階数・数字・操作・警報。Hybridはコードのかごの中へ生成物体を配置し、薄い足元影を加える。外観から重量ルールを変更しない。

## ImageGen Plan / Asset Contract

2行×4列、最後は空白、7個を完全に分離して生成。全身・物体全体・車輪を含め、正面〜わずかな正面斜め、同じ墨線と暖かい抑えた色。透明背景、床・影・数字・文字・ロゴなし。

`passenger-office.webp`、`passenger-courier.webp`、`passenger-visitor.webp`は160×256程度。`cargo-plant.webp`、`cargo-copier.webp`、`cargo-fridge.webp`、`cargo-boxes.webp`は192×256程度。実セルは生成後に検査し、足元/底中央のanchorを記録する。目標130KB以下、必要性を記録した上限180KB。次対象はMobileで60〜80px以上の高さを確保する。

原本と最適化済み会社員・台車をArt Directorが実際に確認し承認。元画像の透明部分には不可視RGB色があるが、採用WebPは透明で、足と台車の全車輪を含む。7個合計88,394bytes。原本/索引`assets/game007/`、配信`public/assets/game007/`。素材承認のみで、完成Visual Gateは別。

## Animation / Error Clarity

モデルの段階に合わせ扉が開き、受諾対象が乗り、拒否対象が去り、降車で表示荷重が減る。超過は超過kgと枠付き警告を見せてから終了。落下・圧迫・怪我の事故描写はしない。20Fの高速移行は判断時間と1.5倍を明示し、受諾後は小さい真鍮の「業務用高速」表示を残す。動きは足し算を邪魔しない。

## Avoid List / Quality Gate

SaaS資源カード、宇宙船エレベーター、小さい数字、色違いだけの客、人物のない重量箱、かごが隠れる密集、悲惨な事故表現を避ける。実Desktop1920×1080/Mobile390×844で次客・減荷・容量直前・超過・20F選択・高速を確認。独立80以上、F12以上、H12以上、最大3回。その後はHUMAN ART REVIEW REQUIRED。人間の暗算感覚と実機性能は未評価。
