# Game002 旅モード Visual Brief

2026-10-04 / Art Director。最新の10ゲーム指示書が会社/旅/バイクの新ゲーム仕様を許可している。今回の美術は、承認済みCOMIC URBANの通勤者・四地区・静かな路面・紙のUIを継承し、全面描き直しはしない。

## Design Goal / Mood

「ゆううつな月曜日 ～WORKDAY DODGE～」の真剣な通勤者が、普通の会社を通り過ぎ、普通のバイクへ出会う。既存の暖かい紙、紺の墨線、黄色い鞄、少し漫画的な大人の街。出社か旅か、乗るか歩くかは到達の報酬とし、タイトルから全展開を見せない。

## Composition / UI

距離mがHUDの主情報。徒歩/旅/バイクは小さい本物の文字で常時示す。会社と駐車バイクは道脇、既存600px画面の中央道路x120〜480へ侵入させない。90px側面しか使えない場合は建物をその領域に収め、コードの弊社看板だけを読みやすい位置へ置く。

到達選択では世界が止まって見え、現在scoreの確定と危険な継続の違いを短く書く。1000mの2択、2000mの3択とも44px以上。320×568でも最下段が切れない。既存の切符/通勤紙の枠、太い日本語見出しと墨線を継承し、黒い巨大パネルを足さない。

## Character / Object Design / Background

普通の3階建て会社（空白看板）、北向きの駐車バイク、同じバイクへ乗る45歳前後の紺スーツ男性（背/頭頂が見え、黄色の鞄を固定）。全部を既存人物/地区シートの近い上方視点と画風に合わせる。豪華なビル、レーサー、ブランド・炎・速度線は不要。旅の先は既存住宅/商店などの背景材を緩やかに再利用できるが、中央道路の見通しを保つ。

## Code / Generated / Hybrid

Generatedは会社・駐車バイク・搭乗バイクの個別透過素材。Codeは「弊社」、選択文章、数字、score、警告、正確な位置・当たり領域・mode。Hybridは生成会社にコード看板、生成車体を実モデル位置に追従させる。画像の大きさから当たり判定を勝手に拡大しない。

## ImageGen Plan / Asset Contract

一つの透過3セルシートに、左から会社/駐車バイク/搭乗バイク。会社に空白の看板を残し、文字は生成しない。バイクは両方北向き、全車輪と鞄を含め、影・背景・文字・ロゴなし。参照は`assets/game002/characters/commuters-source.png`と`backgrounds/districts-source.png`。

`company.webp`192×256、`parked-bike.webp`128×192、`rider-bike.webp`128×192。内容bboxと中心anchorを記録し、モデルの現在中心に合わせる。搭乗バイクの例は42×63表示で既存52×63の人物表現域に収まる。ミラー/鞄は二次的な飾り、主な車体が識別できることを実Mobileで確認。原本/索引`assets/game002/journey/`、採用配信分`public/assets/game002/`。目標3個100KB以下、記録した上限160KB。

実生成原本、最適化会社と搭乗バイクをArt Directorが実際に見て承認した。既存街と同じ墨線/大人の画風、空白看板、北向き/全車輪を確認。3個合計40,072bytes。これは素材承認であり、新イベントのゲーム性・Visual Gate合格ではない。

## Animation / Error Clarity

会社を通過したとき本当に後方へ残す。バイクは許可されたモデルの2倍速度と距離で速さを見せ、無意味なcamera shakeを足さない。薄い車輪反射や鞄の傾きは純粋な装飾で、pauseで止まる。衝突は既存の小さい漫画burst、怪我や事故の見世物にしない。弊社の文字はMobileでも読め、生成画像の文字に頼らない。

## Avoid List / Quality Gate

既存街の全面変更、中央路面へ会社や車体をはみ出させる配置、読めない生成看板、突然大きくなる当たり範囲、ネオンレーサー、怪我描写、開始から全特殊展開を説明することを避ける。実Desktop1920×1080/Mobile390×844で会社選択・通過・駐車バイク選択・搭乗・終了を確認する。独立80以上、F12以上、H12以上、最大3回。不合格継続はHUMAN ART REVIEW REQUIRED。人間の好み・実機性能は別評価。
