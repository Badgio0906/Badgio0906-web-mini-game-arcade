# Game008 コーヒーこぼすな ～COFFEE WALK～ Visual Brief

2026-10-04 / Art Director / HYBRID・朝の街と手触りのあるコーヒー。

## Design Goal / Mood

一人称の朝の散歩。手前の1〜3カップが主役で、操作した身体と遅れて揺れる液体の関係を見せる。Game002の上から見た3レーン通勤にはしない。クリーム#fff1d9、コーヒー#6b3e27、桃#dfa083、セージ#859d87、墨#4d4237。柔らかい墨線と水彩の朝、カフェの紙・陶器の質感。

## Composition / UI

Desktopは広い散歩窓と手前のカップ/トレイ、小さい距離と残量。Mobileでは液体の傾き・イベントの予告・％・左右44px操作を優先。大きい説明カードを液体へ重ねない。カフェ風のセリフ見出し、手書きラベルのような小さな注記、太く読める数値を使う。2杯・3杯になっても全ての液体窓を見せ、小さいアイコンへ縮めない。

## Character / Object Design

紙または陶器のカップに、厚い口、縁の反射、細かい袖/取っ手をコードで描く。内側は実際の液面を描けるclip領域。主人公を手・トレイ・カップの傾きで表現する。モデルが独立した各杯残量を持つ場合だけ各杯％を示し、合計モデルなら「合計」として虚偽の値を足さない。

## Background

低コントラストの目線高さの日本風街路。左右の店・玄関・軒、中央下は静かな路面。道の奥行きが歩いている場面を支え、手前のカップを邪魔しない。画像に描かれた普通の段差/ドアは実イベントの予告の代わりに使わない。実際の危険にはモデルのタイミングに従うコード予告を加える。

## Code / Generated / Hybrid

Generatedは朝の街路画像/参照。Codeはカップの厚い輪郭・袖・clip、実液面・量・慣性・こぼれ・手/トレイ、予告・％・距離・操作。Hybridは生成の静かな朝の世界と、正確に動くコードの前景。液体が固定された不透明カップ画像は使わない。追加cup-shellは内側の完全透過を証明できる場合だけで、必須ではない。

## ImageGen Plan / Asset Contract

`morning-walk.webp`768×512、3:2、目線高さ・浅い遠近法、上1/3付近に水平線、左右に建物、中央下に広い空き路面。人物・車・手・カップ・文字・UI・ロゴなし。暖かい朝日、淡いセージと桃、墨線/水彩の紙。

原本と最適化済み街路をArt Directorが実際に確認し承認。中央下の空間と元の3:2比率を維持。配信1枚67,398bytes、目標80KB以下、上限120KB。原本/索引は`assets/game008/`、採用分`public/assets/game008/`。生成画像の参照承認であり、動く液体の完成度はまだ独立評価していない。

## Animation / Error Clarity

身体/トレイは入力へ反応し、液面は実慣性に従って遅れ、反対へ揺れる。見かけの液体を独立ループで動かさない。実際に縁からこぼれた場所に短い粒を出し、量と％が減る。0％以外を即終了に見せない。500m/1000mの受諾で本当に杯が増え、1.5倍/2倍だけを表示して済ませない。Reduced Motionでも物理状態の情報は消さない。

## Avoid List / Quality Gate

上空からのGame002複製、不透明な生成液面、杯を％カードで代用、ネオンバランス計、極小の液体窓、背景にしかない危険、理由を隠す全画面茶色飛沫、開始時に全てのネタを公開することを避ける。実Desktop1920×1080/Mobile390×844で傾き・遅れ・こぼれ・1/2/3杯・選択・結果を確認。独立80以上、F12以上、H12以上、最大3回。不合格継続はHUMAN ART REVIEW REQUIRED。人間の慣性の理解と実機性能は未評価。
