# 人間プレイテスト — Game001〜010

今回の改修・新作に対する記入用フォーム。**未実施**の欄を自動レビューで埋めない。Game001には過去のA–J合格報告があり、今回の改修でそのコードは変えていない。実際の広告は未接続なので、Hは「広告が出た場合に見たいか」という本人の評価とする。

各ゲームはPCと実機スマートフォンで試す。自然な失敗で3CREDITを使い、開発用Stubで+3した後にも遊びたいかを確かめる。初回の失敗が早すぎた場合や、失敗できない場合もそのまま記録する。攻略用の読み取りplannerの時間は初心者の実測に使わない。

|項目|本人が確認する内容|
|---|---|
|A|説明をほとんど読まず目的と操作が分かるか|
|B|最初の自然な失敗までの時間と、その間の面白さ|
|C|何が原因で失敗したか分かるか|
|D|操作・音・成功演出の感触|
|E|難度の変化が公平で、上達できるか|
|F|自己ベストを更新したいか|
|G|3CREDITを使った後、もう3回遊びたいか|
|H|そのために実際のRewarded Adを選びたいか|
|I|PCの表示・キー・ポインター操作|
|J|実機スマートフォンの縦横表示・タッチ・音・滑らかさ|
|K|ゲーム固有の、さらに先を見たい気持ち|
|L|特殊展開を選ぶか迷う楽しさ|
|M|特殊展開でさらに面白くなるか|
|N|笑いが操作や判断の邪魔にならないか|

A、C–Nは「合格 / 要改善 / 該当なし」と理由を記録。Bは秒数・距離や階数・スコアも記録する。L/Mの分岐を持たない001/004/005では該当なしを選べる。
