# 4. 今回のグラフィック方針

今回の5作品については、ChatGPT側で別途画像生成したキャラクター素材を必要としないものを意図的に選んでいます。

理由：

- 人物アニメーション不要
- 手足・顔不要
- 複雑な動物アニメーション不要
- 幾何学図形と単純な物体で成立
- Codexのコード描画でも品質を担保しやすい

したがって、

**今回、外部参考画像の添付は必須ではありません。**

ただしこれは、

「見た目は適当でよい」

という意味ではありません。

5作品を、

前回のGame020～024で採用した、

- アイボリー
- 深い青緑
- 落ち着いた緑
- 琥珀
- 丸みのあるUI
- 大きな盤面
- 控えめな影
- 読みやすい日本語
- 少しレトロ
- 落ち着いて長時間見られる

方向へ統一してください。

人物の代わりに、

- 球
- 駒
- 盤面
- ラケット
- 釣り針
- 忘れ物
- ケーブル

を主役にしてください。

生成AIで人間を作ってゲームへ入れる必要はありません。

# 5. 定番ゲームの基本方針

今回特に、

Game026「出世すごろく」
Game027「ひと息ビリヤード」
Game028「ぽんぽん卓球」

は定番ゲーム系です。

これらについては、

「100ガレらしくするため」

という理由で基本ゲームを壊さないでください。

不要：

- 突然2倍速
- 強制タイマー
- 突然宇宙
- 爆発
- 派手な裏モード
- 毎回のギャグイベント
- 複雑な通貨
- 不要なキャラクター育成

定番ゲームとして、

**気付いたらもう一局やっていた**

という方向を重視します。

100ガレらしさは、

- タイトル
- 結果コメント
- 控えめな演出
- UI
- 選択肢

程度で加えてください。
