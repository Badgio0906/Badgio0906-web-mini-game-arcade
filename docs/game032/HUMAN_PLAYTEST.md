# Game032 — 人間の試遊

**作者本人・第三者の実試遊は未実施。** ブラウザ自動入力、固定model tests、独立AIによる実画像確認は人間の面白さや実機の触感合格ではない。本人未プレイの技術QA済み試作公開は今回ユーザーが承認している。

PC：`game032.html`のすぐ遊ぶ。A/Dで浅瀬・岩陰・木陰・深みを選び、Spaceを押して離す。小さな揺れを待ち、本アタリでSpace/Enter。強い引きは離し、「巻くチャンス」で長押し。5分終了で釣果／BESTを確認。説明・練習は任意、練習は時間無制限。Esc／休憩ボタンで時計も止まる。

スマホ：左右ボタンで場所、CAST長押し→離す、HOOKタップ、REEL長押し／離す。390／320縦と844横の自動検証は、実iPhone/Androidの長押し・音量・熱・OS割込み・水面の見え方とは区別する。

確認したいこと：川辺の雰囲気は心地よいか／ウキと前・本アタリを読めるか／強い引きのreleaseが理解できるか／場所と距離選択に意味を感じるか／5分が長すぎ・忙しすぎないか／近く・中ほど・遠くの差が伝わるか／もう一釣行したいか。魚種・大物のバランスとレア遭遇を人間で調整する余地がある。

本番Analytics・032ランキングは登録待ちで外部送信OFF。個人BESTは端末内で使える。実機試遊の記録を後日ここへ追加し、AI数値の自己採点へ置き換えない。
