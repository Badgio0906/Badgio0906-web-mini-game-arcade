# 人間試遊の残項目

本人・実機・聴感は未確認。ブラウザ自動操作による合格を、人間が面白いと判定済みに読み替えない。

公開版で「練習する」を選ぶ。川面をタップして投げ先を決め、押して離して投げる。餌＋浮きでは静かに待ち、本アタリで合わせる。弱い引きで長押し、強い引きでは離す。1匹取り込んで水槽の動きを見る。次にルアーへ切り替え、1回ずつ引いて誘う。

- PCと実機縦/横で、少年の独自性/麦わら帽子/手と竿の接合、投げ先の分かりやすさ。
- 水槽の写真調背景と魚の調和、手機で魚種を読めるか、長く眺めたいか。
- 浮きの待ち時間とルアー誘引、合わせ/取り込みのテンポ、実際の音量/耳障り。
- 長時間の誤タップ/発熱/快適性、5分標準と無制限練習の好み。

作者の試遊感想を得てから完成扱いを判断する。今回公開は試作としての継続公開。
