# Game032 revision01 — 固定位置・直接照準・二つの釣り方

対象は `src/games/game032/FishingModel.ts` とモデル単体テストのみ。基準commitは `e3d7338c8fa0f073e0e3ad7ba419375eed3ad0cd`。今回の指示による要求変更であり、旧移動／距離チャージ／不反応時の自動引上げを互換仕様として残さない。

## モデルAPI

- `setTarget(xNorm, powerNorm)` は idle／charging でのみ受付。有限値のみ、横方向は0.06〜0.94、奥行は0〜1へclamp。最寄りの地点から魚種分布と反応率を選ぶ。`playerX`は旧描画契約のため0.14で固定し、左右移動入力は無視する。
- `startCharge()`／`releaseCast()` はアニメーション用に継続。長押しの時間は着水位置を変更しない。確定した `targetPower` が `castPower`／近・中・遠を決める。キャスト以降の照準変更は拒否する。
- `setMethod('bait'|'lure')` は idleのみ。新しいモデルは必ずbaitで開始する。snapshotへ `targetX`／`targetPower`／`method`／`lureProgress`／`lurePulse` を追加。
- `retrieveLure()` はlureのwaitingだけで受付。0.25秒の間隔を置いた一操作につき進行0.1、pulse1。押しっぱなしや時間経過だけで誘引しない。2回目以降に反応抽選し、10回目には少なくとも前アタリを提示する。これは合わせ／取り込みの成功保証ではない。

## 待ちと確率

餌釣りの初回反応機会は2.2〜4.2秒（深み＋1.5秒）。適正距離なら従来の地点反応率、不適距離でも0.63倍の正の確率を維持。外れたら引き上げず、水中で1.8秒後の次の機会を待つ。待機開始から12秒で前アタリを提示し、偏った乱数でも無限待ちにならない。

ルアーはクリック回数による機会。適正距離の誘引率は地点反応率の0.65倍、不適距離は0.38倍。全地点／全距離で正の確率。時間だけでは反応しない。最悪の乱数列でも一回の完全な引きで機会を作る。

前アタリ0.8秒、本アタリ1.6秒（練習2.3秒）、合わせ、引き／休み、巻く／緩める、糸切れ・放置逃げ、魚種／サイズ／得点式／300前景秒は維持する。`no_bite`型は既存互換のため保持するが、この改訂の餌待機では発生させない。
