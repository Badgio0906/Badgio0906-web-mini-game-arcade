==================================================
0. 今回の目的
==================================================

100ガレの新作として、
「低刺激で、つい長く触ってしまう」
「美麗グラフィックで、空気感そのものが価値になる」
「王道寄りで、釣りの気持ちよさを素直に楽しめる」
チル系の清流釣りゲームを実装する。

今回のゲームは、
既存のバカゲー・反射系・短時間ハイテンション系とは少し違う、
落ち着いて遊べる枠として位置づける。

ただし、
雰囲気だけの散歩ゲーにはしない。

必ず、
・どこで釣るか
・どう投げるか
・いつ合わせるか
・どうやり取りするか
というゲームとしての判断と気持ちよさを入れる。

==================================================
1. 完成イメージ
==================================================

プレイヤーは清流の川辺を少しだけ左右に移動し、
釣れそうな場所を選んで釣りをする。

ゲームの手触りは王道寄り。

流れ：
1. 川辺を少し歩く
2. 釣りポイントを選ぶ
3. キャストする
4. アタリを待つ
5. 本アタリで合わせる
6. 魚とやり取りする
7. 釣果と得点を得る
8. 場所を変えてまた釣る

方向性は、
「まったりしているが、ちゃんとゲームとして面白い」
である。

極端なネタ要素や、
不条理な超展開は今回は不要。

100ガレらしさは、
“低刺激だけど続けてしまう”
“少しずつコツが分かっていく”
という方向で出す。

6. 技術方針
==================================================

実装エンジンは、
既存100ガレの構成に合う形を優先する。

原則：
TypeScript + Phaser + Vite
または既存の新作ゲーム実装方式に合わせる。

ただし、
既存共通部品との整合が最優先。

新しい重いゲームエンジンや、
不必要な外部依存は増やさない。

このゲームは3Dでなくてよい。

表現方針：
2Dベース＋レイヤー／パララックス／水面演出／簡易シェーダーやアニメーションで、
「美麗な自然感」を出す。

==================================================
7. モード構成
==================================================

開始導線は100ガレ共通。

最初の導線：
[すぐ遊ぶ]
[説明を見る]
[練習する]

説明・練習は初回でもスキップ可能。

--------------------------------------------------
7-1. すぐ遊ぶ（本番）
--------------------------------------------------

1RUNの記録対象モード。

1RUNは「1回の釣行」とする。

本番は時間制限あり。
ただし短すぎると落ち着けないので、
3分は短すぎる。

推奨：
5分釣行

この5分の中で、
できるだけ高いスコアを目指す。

--------------------------------------------------
7-2. 説明
--------------------------------------------------

説明内容：
・移動方法
・キャスト方法
・アタリの見分け方
・合わせ
・魚とのやり取り
・スコア
・場所による違い

図と短い実演で分かりやすくする。

--------------------------------------------------
7-3. 練習
--------------------------------------------------

時間制限なし、または非常に緩い。

目的：
・キャスト距離を覚える
・前アタリと本アタリを知る
・テンションゲージの扱いを学ぶ

練習では
・記録保存なし
・BEST反映なし
・ランキング送信なし

必要なら、
練習では魚がやや掛かりやすくてもよい。

==================================================
8. プレイフィールド
==================================================

川辺の横長マップ1つを作る。

イメージ：
・清流
・石
・苔
・草
・木
・木漏れ日
・流木
・浅瀬
・少し深い淵
・流れの強弱

プレイヤーは川岸を左右に少し移動できる。

完全なオープンワールドにはしない。
あくまで「少し歩いて釣り場を選ぶ」程度。

釣りポイントは3～5か所程度に設ける。

例：
1. 浅瀬のゆるい流れ
2. 岩陰
3. 木の枝がせり出した場所
4. 深み
5. 流れ込みの近く

見た目の違いだけでなく、
釣れやすい魚や大物率に差をつける。

==================================================
9. プレイヤーキャラクター
==================================================

主人公は、
シンプルな釣り人。

必要以上に顔を大写しにしなくてよい。

見え方：
・横向きまたは斜め横向き
・帽子 or 普通のアウトドア服
・自然な服装
・落ち着いた色味
・悪目立ちしない

このゲームでは主役は風景と釣り。
キャラは背景に負けない程度でよいが、
雑な棒人間にはしない。

待機、歩き、構える、投げる、合わせる、リールを巻く、釣り上げる、
のアニメーションを用意する。

==================================================
10. 操作
==================================================

--------------------------------------------------
10-1. PC
--------------------------------------------------

移動：
A / D
または ← / →

キャスト準備・決定：
Space長押し → 離す

合わせ：
Space または Enter

やり取り中の巻き：
Space長押し
または Enter長押し

必要に応じて、
やり取り中の左右入力で少し魚の動きへ対応してもよいが、
複雑にしすぎない。

--------------------------------------------------
10-2. スマホ
--------------------------------------------------

左右移動：
左右ボタン
または大きな仮想ボタン

キャスト：
JUMPの代わりに大きな「CAST」ボタン長押し → 離す

合わせ：
大きな「HOOK」ボタン

巻き：
大きな「REEL」ボタン

スマホでは誤操作しやすいので、
ボタン数を増やしすぎない。

長押しでテキスト選択やブラウザの変な挙動が出ないよう、
既存の長押し対策ルールを適用する。

==================================================
11. 釣りのコアループ
==================================================

--------------------------------------------------
11-1. 場所を選ぶ
--------------------------------------------------

プレイヤーは川辺を歩き、
好きなポイントで竿を出す。

場所ごとの違いを作る。

例：
・浅瀬：小型が多い、数は釣れやすい
・岩陰：中型が出やすい
・深み：大物率が高いが掛かりにくい
・流れ込み：活性高め
・木陰：レア魚率少し高め

--------------------------------------------------
11-2. キャスト
--------------------------------------------------

キャストは長押しチャージ式。

短い：
近くへ投げる

長い：
遠くへ投げる

遠投すれば良いわけではなく、
場所ごとに適切な距離がある。

水面に着水した位置が、
魚の反応率へ影響する。

キャストは気持ちよく見せること。
糸、竿、ルアー or ウキの軌道、着水波紋を丁寧に作る。

--------------------------------------------------
11-3. アタリ待ち
--------------------------------------------------

キャスト後は、
少し待つ時間がある。

完全放置ゲーにはしないが、
慌ただしくしすぎない。

前アタリ：
・ウキが少し揺れる
・糸がわずかに引かれる
・水面に小さな波

本アタリ：
・ウキが大きく沈む
・強い引き
・SE変化

前アタリで早合わせすると失敗しやすい。
本アタリで合わせると成功しやすい。

--------------------------------------------------
11-4. 合わせ
--------------------------------------------------

本アタリのタイミングで、
HOOK操作を行う。

早すぎる：
すっぽ抜け

遅すぎる：
逃げる

成功：
魚が掛かる

初心者にも分かるよう、
完全にシビアにしすぎない。

練習モードでは、
タイミング判定を少し甘くしてよい。

--------------------------------------------------
11-5. やり取り（ファイト）
--------------------------------------------------

魚が掛かった後、
このゲームのもう一つの気持ちよさを作る。

システムはシンプルでよい。

基本：
・テンションゲージ
・魚の暴れ
・魚が疲れた時に巻く
・無理に巻きすぎると糸切れ

推奨仕様：
魚が強く引いている間に巻きすぎるとテンション上昇
テンションMAXでバラし
魚の引きが弱い瞬間は巻きチャンス
数回のやり取りで取り込める

大型魚ほど時間がかかる。

ただし、
1匹で長すぎるとテンポが悪いので、
通常魚は5～12秒程度で決着する想定。

大物はもう少し長くてもよい。

==================================================
12. 魚種
==================================================

最初の実装では、
6～8種程度でよい。

例：
・オイカワ
・ウグイ
・ヤマメ
・アマゴ
・ニジマス
・イワナ
・ブラックバス（場違い気味の少し特殊枠としてもよい）
・川の主（超レア）

完全なリアル図鑑でなくてもよいが、
それっぽさは大切にする。

魚ごとに設定：
・出現ポイント傾向
・出現率
・サイズ帯
・引きの強さ
・基本点
・レア度

==================================================
13. スコア設計
==================================================

今回の全体ランキング対象指標は、
「1釣行の総合スコア」とする。

高いほど良い。

理由：
・王道の釣りゲームとして競争しやすい
・サイズ、種類、数を総合できる
・TOP10に向いている

推奨スコア構成：

魚1匹ごとの得点 =
魚種基本点
+ サイズボーナス
+ レア魚ボーナス
+ 大物ボーナス
+ 連続成功ボーナス（軽め）

例イメージ：
小魚 30～70点
中型 100～180点
大型 220～400点
川の主級 700点以上

ただし、
最終的な数値はテストで調整する。

1RUNの終わりに表示するもの：
・総合スコア
・釣った匹数
・最大サイズ
・釣った魚の内訳
・新記録かどうか

==================================================
17. グラフィック方針
==================================================

今回の価値の大きな部分は見た目。

絶対に、
Codexにありがちな
「無機質な図形だけ」
「気持ち悪い人体」
「安っぽい仮UI」
のまま終わらせない。

必ず、
Art Director工程を入れること。

推奨工程：
1. ビジュアル方針を定義
2. 画像生成スキルでコンセプトアート／背景／UI素材を制作
3. 必要なら複数案を比較
4. 実装に統合
5. スクリーンショットを見て修正
6. QA

スタイルの方向性：
・美麗
・柔らかい自然光
・透明感のある水
・イラスト寄りの高品質2D
・落ち着いたUI
・派手すぎず、地味すぎない
・“少し高級なチルゲーム”感

==================================================
23. 難易度バランス
==================================================

目標：
「気持ちよく釣れるが、雑だと損する」

やさしすぎると退屈、
難しすぎるとチルではなくなる。

本番5分での理想体験イメージ：
・数匹は普通に釣れる
・うまいと高得点
・大物が掛かると少し緊張
・ポイント選びとキャストで差が出る
・静かだが、上達の余地がある

完全放置で最高記録が出る設計にはしない。

==================================================
24. ゲームの弱さを避けるための注意
==================================================

次の失敗を避ける：

・ただ待つだけで退屈
・魚が掛かるまで何も起こらない
・どこで釣っても同じ
・キャストが適当でも同じ
・ファイトが単調
・景色は綺麗だがゲーム性が薄い
・逆に忙しすぎてチルではない
・UIがうるさい
・操作が多すぎる

つまり、
空気感 + 小さな判断の積み重ね
を成立させること。
