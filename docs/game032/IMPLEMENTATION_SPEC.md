## 遊びと実装範囲

清流の一枚の世界で、浅瀬／岩陰／木陰／深みの4地点へ移動し、距離を選んで投げ、本アタリで合わせ、強い引きを緩めて弱い引きを巻く。過剰な巻きは糸切れ、巻かないままでは逃げる。失敗で釣行は終わらない。地点の好みの距離、魚種分布、大物傾向、待ち時間が異なる。開けた世界／敵／クラフト／CREDIT消費は追加しない。

本番は**活動時間300秒**。Pause・非表示では時計／魚を停止し、復帰に新しい操作が必要。練習は別モデル・時間無制限で、BEST／記録共有／production RUNへ混ぜない。画面は説明・実際の練習・即本番を初回から自由に選べる。

PCはA/D・矢印で移動、Spaceの長押しとreleaseで投げ、Space/Enterで合わせ／巻き、Escで休憩。スマホは左右ボタンとphaseでCAST/HOOK/REELに変わる大きな操作ボタン。pointercapture・cancel・lostcapture・タブ非表示を解除し、前画面のrelease/clickを新画面へ持ち越さない。

チャージ1.25秒で最大、near<.34／medium<.74／far。投げ.9秒、前アタリ.8秒、本アタリ猶予1.6秒（練習2.3秒）。通常魚の適応した操作は5〜12秒程度を設計値とし、主は長め。モデルと計測の詳細は[MODEL_SPEC](MODEL_SPEC.md)。

## 技術・素材・保存

既存TypeScript/Viteに、2D Canvas描画を追加。重い新エンジンやパッケージを追加せず、純粋モデル／描画・入力／保存／音を分離。画像生成を実3回使った川辺背景・人物8ポーズ・魚6種。原本・prompt・出典・全SHA・最適化手順は[Art](ART_DIRECTION.md)と[素材台帳](../../assets/game032/asset-index.json)。自然な人体の8ポーズの足元・竿の接続anchorを固定し、水面cropと投げ先の射影を共通計算する。

公開15画像は合計1,180,616bytes。人物／魚は透明WebP。独自の小さな波紋・魚影・糸・竿・投げ軌道を重ねる。背景の木漏れ日・草は生成絵に含まれる。軽い水音／鳥声／操作SEはコード合成で既存mute方針に従う。派手な点滅や画面揺れを足さない。

Canvas解像度倍率は1.5上限。background非表示中は不要な描画を止める。定数個の素材／AudioContextを使い、毎釣果にAudioContextや粒子配列を増設しない。実機の熱・音・長時間memory保証は未評価。
