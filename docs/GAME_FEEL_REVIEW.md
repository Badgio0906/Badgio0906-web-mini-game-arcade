# ORBIT SHIFT — Game Feel Review

実施日: 2026-10-04（日本時間）
担当: Game Feel Reviewer（実装担当とは別エージェント）

## 方法と限界

Chromium を実際に起動し、Phaser の描画結果、Space 入力、タッチ相当入力、結果画面と CREDIT フローを確認した。デスクトップ 1366×900、スマートフォン縦 390×844、横 844×390 を使用。診断 API は位置・障害物の読み取りだけに使い、操作は実際のキーボード／タッチ経路を通した。死亡強制、位置移動、時間送りは使用していない。

スクリーンショットを見て視認性を確認した。自動操作の生存時間は人間の初心者・上級者の成績ではない。面白さ、指での気持ちよさ、音の聞き心地、リトライ欲求、広告を見たいかは人間による評価が必要であり、合格と断定しない。

## 実行で確認したこと

| 観点 | 観察と判断 |
| --- | --- |
| 最初の 10 秒 | 開始後はすぐ機体が回り、入力できる。最初の約 1.5 秒は落ち着いた空間、次いで障害物が見えてくる。約 4 秒の画面で近づく障害物を確認できた。放置した最初の死亡はゲーム時間 5.877 秒。初見 3 秒死亡を避ける調整は反映済みだが、初心者の 20〜60 秒という目安は人間で計測する必要がある。 |
| 操作理解 | タイトルに TAP / SPACE、デスクトップに Space / Enter の短い表示。Space とスマホの盤面タップで INNER → OUTER を確認。140ms の切替中も時計回りの移動が続く。 |
| 要素の識別 | ミントの方向を持つ三角機、赤い × 付き障害物、金色の菱形 Shard をスクリーンショットで区別できた。色だけに頼らない形の差がある。 |
| 安全なプレイ | 障害物の衝突端の約 0.8 秒前に Space を押す自動操作で 30.02 秒生存、11 回切替、スコア 1,350、Near Miss Combo 0。危険な切替なしでもスコアと収集が成立した。 |
| Near Miss とリスク | 約 0.22 秒前に切り替える操作で 95.03 秒まで生存、48 回切替、最大 Combo 48、スコア 42,490。30 秒時点の画面はスコア 8,392。安全操作とは獲得点に明確な差があり、プレイ時間だけで決まるスコアではない。Near Miss の点数は回避成功後に表示される。スマホの直接タッチ相当入力でも 0.22 秒前の切替で生存し、6.19 秒時点で +100／Combo 1 を確認。0.02 秒前では 5.876 秒に死亡し、Combo 0。単に切替を押せばボーナスになる仕組みではない。 |
| 難易度 | 実行中に EASY → NORMAL → HARD → VERY HARD を確認。95 秒までの観察で、前触れなく現れる障害物や、両レーン同時閉鎖には遭遇しなかった。有限の実行例であり、全乱数パターンの証明は QA の領域。 |
| ミスの説明 | 衝突で機体が破片になり、その後「障害物に接触しました」と結果を表示。スコア、BEST、TIME、MAX COMBO、自己ベスト更新、残り CREDIT が見える。実際の死亡理由の理解しやすさは C で確認する。 |
| リトライ | 結果表示後の RETRY クリックから次の生存状態まで約 504ms。ロード画面は挟まない。遅い演出待ちなしに次のフライトへ移れる。 |
| CREDIT 0 | スマホ相当画面で自然死亡 3 回を実施。3 → 2 → 1 → 0、「NO CREDIT」「+3 CREDIT」選択肢、開発用 Stub の表示を確認。+3 CREDIT をタップすると 3 に戻り、次のプレイが始まる。 |
| 画面サイズ | 縦画面の盤面は 358×358、横画面は 276×276。どちらも盤面・CREDIT・主要ボタンを画面内で確認し、タップで切り替えできた。小さい横画面での快適さは実機確認が必要。 |

## 指摘と再確認

### P2: 小さい画面の成功フィードバック／結果要約（修正・再確認）

初回確認の Near Miss ポップアップは 600px 基準の 15px 文字で、縦スマホの 358px 盤面では約 9px 相当になる。NO CREDIT 画面の SCORE / BEST / TIME / MAX COMBO の要約も小さかった。高得点を狙う理由を伝える情報なので、拡大を提案した。Main Agent はポップアップを 22px の 2 行表示にし、幅に応じて横位置を制限、結果要約を 2 列／縦 12px・横 10px に修正。タッチで Near Miss を実際に発生させて、縦・横とも文字が盤面内に収まり、危険物を隠さないことをスクリーンショットで再確認した。

要約拡大の初回修正では縦画面の Stub 説明が盤面の下端で切れる問題を検出し、Main Agent に戻した。最終のコンパクトな余白調整後、自然死亡 3 回を縦・横それぞれ再実施。縦はカード 347.48px が盤面 358px 内、横はカード 263.56px が盤面 276px 内に収まり、Stub の 2 行とも表示された。P2 は修正後の実行確認まで完了。

### 人間で判断する項目

初心者が 20〜60 秒生存できるか、0.22 秒付近の切替を人間が狙えるか、Shard を取るための戻りが魅力的か、Combo の伸びとリセットを理解できるかは未確定。自動操作が長く生存できることと、人間にとって適正な難易度であることは別の評価である。
