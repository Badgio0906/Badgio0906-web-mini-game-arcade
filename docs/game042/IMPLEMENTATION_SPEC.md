# 企画03｜一閃、まとめて。 ～DASH CHAIN～

## 企画の核
**「その一筆で、六体まとめて。」**
ネオンに照らされた舞台で、成人の女性剣士が紙面の妖怪を斬り抜ける。指で短い経路を引き、離した瞬間にその線を高速ダッシュ。敵を一筆でまとめて斬るほど数字と斬撃音が跳ね上がる。

タイミング1点のパリィではなく、**どの順に通れば一度で多く倒せるか**を瞬間的に描く経路アクション。血やリアルな負傷ではなく、敵が仮面・紙片・光へ弾ける。

## 固定ルール・入力
- 論理戦場480×480。主人公初期位置(240,430)、判定半径12。ライフ3、制限60秒。
- PCの左drag、スマホ操作パッドのdragで経路を作りreleaseで実行。押し始め位置に依存せず「主人公位置＋指の移動量」で経路を引く。指が戦場を覆いすぎない位置へ半透明予告を表示。
- 経路長は最大560px、描画時間は最大1秒。長さ上限で先端を止め、勝手に余剰線を延ばさない。点は6px以上の間隔で追加、最大96点。
- release時に20px未満なら取消。1秒を超えたら経路は固定して「離して斬る」、自動発動はしない。描いている間も敵の予兆・時計は通常進行。
- ダッシュ速度1800px/秒。全経路を瞬間teleportせず区間ごとの連続衝突判定。移動後の位置が次の経路の出発点。
- ダッシュ中だけ敵の攻撃ダメージを無効にする。終了後0.35秒は次ダッシュ不可。ここは無敵ではない。
- pointercancel/blurでは経路を破棄し、攻撃しない。pause中は主人公/敵/経路を保全し、再開後に新しいpressからやり直す。
- キーボード代替：Space保持中に矢印で仮想描画点を移動、Space releaseで発動。タッチと同じモデル関数。

## 敵・障害物・ステージ
0〜48秒は6秒ごとに6体の群れを8回出す。各群は出現5.5秒で退場予告、6秒で残った敵が煙とともに退場（点0）。同tickの既存攻撃を確定後に退場、次群を出す。説明のない削除や無限蓄積はせず、同時最大12体。48秒に最後の群れが退場してボスへ移る。

- 紙鬼：耐久1、半径18、100点。ダッシュ区間が触れれば斬れる。
- 盾鬼：耐久1、半径20、200点。向きは出現時に決め、矢印を表示。その群れの間は回転しない。前方±60度の接触は防ぐ。接触直前の主人公位置が前面円錐内なら不成立、側面・背面は撃破。正面接触はその接触点の手前でダッシュ終了。主人公へ直接ダメージは与えず、盾音と停止で結果を示す。
- 柱：1群最大1本。軸平行矩形で、ダッシュが当たればその手前で止まる。壁越しの敵へ判定を通さない。
- 敵は出現2.4秒後に狙う地点を固定し、半径65の攻撃予兆を0.9秒表示してから攻撃。予兆位置はプレイヤーを追尾し続けない。攻撃後は再度1.5秒以上の予告を挟む。
- 被弾はライフ-1、0.7秒無敵、ノックバックは短くして画面外へ飛ばさない。

最初の群れは紙鬼6体のみ：
(240,360)、(170,315)、(240,270)、(310,225)、(240,180)、(240,110)。
初期位置から順に通る折れ線は560px以内。初見でも一本線で複数体をまとめられることを最初の快感にする。

48秒でボス「六面鬼」登場。耐久3、巨大盾の向きと背面の弱点を表示。ダッシュ1回につき最大1ダメージ。再び弱点が開くまで0.8秒。盾の向きを変える時は0.6秒以上の予告。60秒までに3回斬ればクリア。最後の攻撃とライフ0が同tickなら失敗優先。

## 得点・爽快感
1ダッシュ内の撃破順kに対し `floor(基本点 * min(25,10+2*(k-1))/10)`。
同一敵は同じactionIdから1回しか被弾しない。経路を往復しても水増し不可。異なるダッシュで既に消えた敵を再加点しない。

1ダッシュ3体で「三閃」、6体で「一閃六断」。一連の斬撃音は60ms程度ずつ上昇。敵が白黒の仮面片に割れ、最後に金の輪が広がる。ボス撃破2000点、クリア1000＋残ライフ×400。

ヒットストップは最初の主要撃破に25ms、6体達成時に35msまで。1ダッシュ合計60ms以下。敵1体ごと無制限停止は禁止。モデル時計も同じ停止時間を使う。

## 素材・ImageGenブリーフ
基準：成人の女性剣士、紺と朱の現代和装、短い上着、長い布の帯。刀身そのものを主役にしすぎず、シルエットと目元に個性。通常・抜刀・勝利3枚。ゲーム内は立ち絵の短い移動・残像、骨格アニメ不要。

プロンプト核：
「高品質オリジナル2Dアクション用。ネオンの祭り舞台、藍と朱と金の配色。成人の女性剣士／指定された紙仮面の敵を1体だけ。輪郭が明快で、ゲーム表示で目線と武器方向が分かる。キレのあるアニメ塗り、派手な光は控えめに素材を分離。透明背景。文字・UI・血・既存作品のキャラクターなし。」
背景1、主人公3、紙鬼/盾鬼、ボス、柱。経路線・斬撃・文字はコード。色だけで敵向きを区別しない。

## 固有QA・実装順
まず初期6体を手入力の1経路で斬るモデルとプレビューを完成。次に盾の前/横/背面、最後に敵予兆とボス。

必須：経路長の厳密制限、重複点、0長区間、交差経路、角での衝突、柱先端停止、盾側の判定境界、ダッシュの無敵開始/終了、ボス一撃1回、入力中断、30/60/120Hz。

設計検算は最初の6体へ届く折れ線長と別ID6体のみ。実際の盾・敵時間・全8群攻略は未検証。人間向けの分かりやすさは手入力QAで確認し、全部をsolver自動操作で済ませない。

技術試遊合格：4幅で3体以上の一筆斬り、初期6体斬り、正面盾を避けた撃破、60秒内ボス撃破、ライフ0失敗、retryを再現。rank Sはクリア/6体一筆を2回/被弾0、Aはクリア/1回、Bはその他クリア。目標未達なら配置を調整し、判定線を見た目より広げて偽装しない。
