# Game005 コンボ・フィーバー改修 V2

ユーザーの第3工程。基本は既存の左右仕分け・4属性・8個ごとのルール切替を保つ。形→明るさ→大きさ→記号、その後左右反転。切替時は0.95秒荷物なし・入力不可で、新しい判定ルールを表示する。

- 間違いと時間切れを各1ミスとして、3回目で終了。1・2回目は0.8秒正解表示のあと継続。ミスで連続正解とフィーバー充填をリセット。
- 正解1個は`round((100 + round(50 × 残時間比)) × コンボ倍率 × フィーバー倍率)`点。コンボ1〜4個×1、5〜8個×1.25、その後4個ごと+0.25、最大×2.75。
- 通常中の8連続で6秒フィーバー。得点×2、配送0.23→0.12秒、次の荷物の制限時間×0.8。フィーバーは延長しない。終了後もう一度8個を目指す。進行時間はpause中に進まない。各荷物の期限は出現時固定し、フィーバー終了途中に変えない。
- BESTは同じnamespaceの`best-rules-v2`へ新規保存。旧`best`は読取り表示だけ、書換・移行・再送しない。
- 今回は既存美術を保持。紫の工場・ルール看板を主役とし、フィーバーは暖色の帯と枠だけで判定対象の形・明暗・大きさ・記号を隠さない。残ミス・8個ゲージ・残フィーバー秒数・次の倍率を同じ帯に表示。

Core Loopはルールを読む→正しく速く仕分ける→8個を目指す→短いフィーバーで稼ぐ→通常へ。Skillは視覚分類・ルール切替・正確さと速さ。再挑戦目標は最大コンボ・複数回フィーバー・得点。プレイ時間の人間実測と面白さは未確認。

共通records/gameVersions/ランキング登録はroot統合担当。独立練習は既存onboardingを保ち、本番得点/BESTへ書かない。
