# Visual brief

このチャットの添付inline参考画像（5作品、右下PLUG ROUTE）を実際に見て方向性を参照。originalファイル名／寸法／ローカル原本は親の共通素材台帳担当で、このauthorは未確認。本文だけを実画像照合としない。画像そのもの、参考製品のasset/UI/map/codeは複製しない。アイボリー床、平面の机・棚・箱、深緑コード、琥珀の2本端子プラグ、白い差し込み穴付きコンセントを独自SVGで描画。植物・人物・腕などを勝手に追加しない。

盤面は画面に実在し、遊ぶ対象。通常viewportで全盤面が見え、文字・コードと背景を区別できること。短い横向きはcontrolsを横へ移動。指の上のplug previewは実プラグと同じ操作を示す補助。大きな不透明カードで盤面を隠さない。hintは一点だけ。通常・hover・focus・disabledを明示、primary hoverは暗緑＋白で保持。独立実画像評価は未実施、前バッチ点数を流用しない。
