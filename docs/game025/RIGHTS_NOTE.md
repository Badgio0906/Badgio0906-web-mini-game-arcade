# 権利・素材の確認範囲

古典Minesweeperの数字・隣接・旗という抽象ルールを独自コードで実装。盤面、推測なし生成器、見える情報のみのsolver、図形、旗、説明文とWebAudio音は当プロジェクトで制作し、他サイトのコード／画像／盤面／音声／UIは転用していない。サムネイルは本ゲームの実際の通常盤面から作成する。外部画像素材や新規ライブラリは追加しない。

「こつこつマインスイーパー」の今回の限定名称検索では完全一致作品を確認しなかった。英題MINESWEEPERは一般的なルール名として使う。他社ロゴやWindowsの固有外観は採用しない。商標の網羅的確認、日本法上の個別クリアランス、ゼロリスク保証は行っていない。[調査のURL・取得範囲](../classic-five/RIGHTS_NOTE.md)を参照。
