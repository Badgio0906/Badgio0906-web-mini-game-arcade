# Game037 — Game Feel review（**自己評価**・独立レビューではない）

実装者（Claude Code）本人による観察と設計上の判断。人間の試遊・独立Feel reviewは未実施。ブラウザ操作は自動化された正解手順（solverの解）であり、人間の思考時間・迷い・楽しさを表さない。対象ソース `fd3eca9`。

## 最初の10秒
- タイトルに完成済みの弁当（solverの解をそのまま描画）が見え、「この箱をこう埋める」が言葉なしで分かる。
- 「すぐ遊ぶ／練習する／遊び方」の3択。説明・練習は任意。
- 本番開始直後に「おかずを選んで、弁当箱へ詰めましょう。」と表示。おかずを持ち上げるとマスに吸着し、緑なら置ける。

## 操作感（実装上の確認）
- drag：8pxの遊びでtapと区別。合法時はghostがマスへ吸着（スナップ）し、離す前に結果が分かる。不可は赤×で理由（はみ出し／重なり）を表示、罰点なし。
- tap：「タップしたマスにおかずの左上の具が入る」。合わなければ次の具で合わせるため、だいたい狙った所に入る。PCでは選択中にホバーでプレビュー。
- keyboard：1〜4で選択→矢印→R→Enter。押しっぱなし（repeat）は無視。
- 取り外し：配置済みをタップ/ドラッグ。-50が状況表示とHUD「この弁当」に即反映され、減点が見える。
- 自動化中に発見・修正した操作の問題：①次の面へ進むとトレイのボタンが無効のまま（時計再開時に再描画していなかった）、②L/T/S等のbbox空き角をタップすると隣のおかずが外れる（DOM矩形の当たり判定）→マス占有で判定、③タッチのタップが`detail 0`のclickを伴いキーボード操作扱いになる、④盤タップで青いタップハイライト。いずれも修正後に再テスト済み。

## 得点と再挑戦（仮説）
- 1面1000点から時間・回転・取外しで減点。「回さずに置けるか」「取り外さずに一発で詰められるか」に工夫の余地があり、BEST更新の動機になる仮説。
- 6面は固定なので、2回目以降は記憶で速くなる。リプレイ性は「操作の無駄を削る」方向に限られる（ランダム面・追加面は割当で禁止）。
- 制限時間・失敗が無いため緊張感は低い。チルな詰め物パズルとしての位置付け。

## 中断と公正さ
- 休憩・タブ切替（hidden）・ウィンドウblurで時計停止し、選択とdragを解除。再開時は選び直し（入力の持越し無し）。
- 面クリア時点で時計停止。「次の弁当へ」を押すまで次の時計は始まらない。

## 未確認（人間が必要）
- 実際の初見プレイ時間（設計仮説90〜180秒）、迷う面、BESTを更新したくなるか、効果音の心地よさ、実機タッチの指の隠れ（drag中にghostが指の下になる）。


## Rules v2（箱が大きくなる版）の観察（自己評価・人間未実施）
- 4×4の6面で操作を覚えた後、5×5で5マス前後のおかずが出て形の読み方が変わる。8×8は9個（上限10）の大きめのおかずで、置き順を考える比重が増える（設計上の意図。実際の難しさは未計測）。
- 得点の減点は大きい箱ほど薄まるため、大きい箱でも1面あたりの点は800〜900台に収まりやすい（自動操作の秒数での確認であり、人間の所要時間ではない）。
- 全30弁当は長いので、箱ごとの「つづきから」と、弁当ごとのBEST更新で、途中でやめても無駄にならない作りにした。
- QA中に、HUDの折り返しでプレイ中に盤面が動く不具合を発見・修正した（ドラッグ中だと1マスずれて置けない）。
- 未確認：人間が8×8を何分で解くか、詰まる面、5×5→6×6の難度の跳ね方、スマホ縦で9個のおかずを並べた時の選びやすさ。
