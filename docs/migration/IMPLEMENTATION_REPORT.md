# 14ゲーム統合とGame011改修

今回の指示ではGame011の回答時間・配点を変更し、既存3ゲームをゲームセンターに統合します。川俣さんのゲームは移行・変更・公開停止の対象外です。

## 回答時間とスコア

| 通算の問題番号 | 回答時間 | 正解の得点 |
|---|---:|---:|
| 1〜20 | 2秒 | 100点 |
| 21〜50 | 1.5秒 | 200点 |
| 51以降 | 0.5秒 | 500点 |

画像10問と文章10問を終えた次の問題が21問目です。文章の読解時間とFinalのモード選択は無制限。準備OKを離した後に回答時計を開始します。50問正解で8000点、51問正解で8500点です。新配点のBESTは別保存し、旧配点の記録を消さず「旧BEST」と表示します。

3ゲームの既存Web版は合計141,422,287 bytesで、元のGodotエンジン・PCK・音声を保持します。ポータルのカード画像は実ゲームの保存済みスクリーンショットを使い、ゲーム本体は選択時に読み込みます。新3本は既存のチュートリアル・保存仕様を保ち、001〜011の共通UIへ置き換えていません。
